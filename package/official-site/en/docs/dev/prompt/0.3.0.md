## Scheduled Task Feature

Implement a scheduled task feature with 3 modes:

1. **Off**: No scheduled tasks are executed.
2. **Interval Loop**: Execute tasks at a fixed interval (e.g., every N hours/days).
3. **Weekly Custom**: Select specific days of the week and times to execute tasks (e.g., every Monday at 9:00 AM and Friday at 6:00 PM).

### Frontend

- Add a scheduled task configuration section in the settings page.
- For "Interval Loop" mode, provide an input for the interval duration and unit (minutes/hours/days).
- For "Weekly Custom" mode, provide a day-of-week selector (multi-select) and a time picker.

### Backend

- Store scheduled task configuration in the system configuration.
- Implement a background scheduler that checks and triggers tasks based on the configured schedule.

## Task Processing Refactoring

Refactor the task processing module to use the Strategy + Factory pattern:

1. Define a common task handler interface (Strategy).
2. Use a Factory to create the appropriate task handler based on the task type.
3. This allows adding new task types without modifying existing code (Open/Closed Principle).
4. Improve code maintainability and testability.
