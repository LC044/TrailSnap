# TrailSnap 0.21.0：智能 CLIP 分类与人物时光线，重塑影像管理体验

TrailSnap v0.21.0 版本现已发布！本次更新带来了从底层识别算法到用户交互的全面革新，助您更高效地管理海量影像资源。



### 核心亮点：智能 CLIP 多标签分类 —— 重塑您的图库逻辑

在本次 v0.21.0 更新中，我们彻底重构了图库的分类体系。告别了传统分类的机械与单一，全新的 **智能 CLIP 多标签分类系统** 能够像人类一样“看懂”照片的内容，为您提供前所未有的智能组织体验。

#### 1. 行业领先的识别基底
系统内置了 **11 组共 166 类** 经过深度校准的默认分类目录。从复杂的自然风光到细微的活动场景，CLIP 模型能精准捕获图像特征。针对不同类型的照片，我们逐类优化了识别阈值，确保分类结果不仅“多”，而且“准”。

![自然风景分类分组概览](https://blog.siyuan.ink/static/img/fb04205e0cc078f8164734c5808a306f.01-clip-overview.webp)

#### 2. 无限可能的自定义规则
如果您有更个性化的整理需求，新的自定义分类规则将是您的得力助手：
*   **语义描述**：只需用简单的自然语言描述（如“草地或山谷里的露营帐篷”），AI 就能在图库中定位符合条件的影像。
*   **参考图学习**：支持从图库中挑选参考照片，并进行**局部目标区域裁剪**。只需告诉 AI 关注图片的哪一部分，它就能精准识别该特征，不再被无关背景干扰。
*   **预览与验证**：在规则应用前，系统支持即时预览匹配结果，并支持对模型匹配阈值进行高级微调，确保逻辑精准贴合您的心意。

![新建分类规则与高级匹配阈值设置](https://blog.siyuan.ink/static/img/30513861d67246744afa1cbd78e00365.03-clip-new-category.webp)

#### 3. 灵活可控的 AI 协助
我们深知自动化不等于放弃控制。智能分类系统提供以下保障：
*   **人工干预机制**：您可以随时手动保留或排除某张照片，纠正 AI 的判断，并让这些调整被记录。
*   **规则版本化**：所有自定义规则支持版本管理。您可以随时调整阈值、更新描述词或更换参考图，并一键触发历史照片的重新扫描与归类，确保图库逻辑始终符合您的最新需求。

### 全量照片清理：更强大的后台扫描
应对照片堆积，v0.21.0 引入了全量清理模式。无论是重复照片还是相似影像，现在均可在后台稳定扫描，不再受限于单次数量上限。

![全量照片清理操作](https://blog.siyuan.ink/static/img/d5658d7e79562ea714c11bb7f782d796.05-duplicates-cleanup.webp)

### 人物相册深度挖掘
人物相册不仅是照片的集合，更是您的记忆时光线。本次更新优化了人物查找与匹配算法，您可以自定义匹配距离参数，轻松找出相册中漏网的珍贵影像。

![人物相册管理](https://blog.siyuan.ink/static/img/b056d1814d7fa4678c47516429834276.06-people-clean.webp)

### 更多优化
- **飞牛迁移支持**：Docker 用户现可无缝迁移至飞牛 fnOS 部署。
- **任务实时推送**：大幅优化了后台任务的更新频率。
- **操作体验简化**：工具箱与人物操作细节精简，交互更加流畅直观。
