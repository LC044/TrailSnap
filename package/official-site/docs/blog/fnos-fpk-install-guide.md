# 给飞牛 NAS 装个 AI 相册：行影集 TrailSnap 的 .fpk 安装实录

相信大家组 NAS 的一大刚需就是存照片。手机拍的、相机导的、家人微信群里发的一股脑全塞进共享文件夹，几年下来攒了几个 T。结果真想找一张「去年在海边拍的日落」，只能对着文件管理器一层层点开盲猜，翻到一半直接放弃……

今天给大家安利一款开源的私人 AI 相册——**行影集 TrailSnap**。最省心的是，它现在出了**飞牛官方 `.fpk` 安装包**！直接在应用中心手动上传就能装，**完全不用自己去折腾 Docker Compose 改配置文件**。

核心就一句话：**把 NAS 里的老照片接进来，让本地 AI 按人物、场景、足迹自动整理，搜图直接打字描述画面就行。数据全留本地，不上传、不外传，纯 CPU 也能跑！**

![行影集首页](https://blog.siyuan.ink/static/img/b46b5740584f647e9ee7120435910dfe.01-home.webp)

## 一、 先看颜值与核心玩法（不止是个看图软件）

装好之后它是一个非常完整的 Web 相册应用，而且有很多专为摄影和旅行党设计的细节：

**1. 懂画面的「一句话搜图」**

不用提前打标签！直接搜「海边看日落的照片」，AI 读的是画面内容而不是文件名。甚至能直接问它：「我去年国庆去了哪些地方？」

**2. 多标签智能分类 + 自定义训练**

不同于传统相册“一张图只能归一类”，一张雪山下的湖泊可以同时拥有「雪山」「湖泊」「自然风景」多个标签。内置 170+ 精细分类，还能**喂给它几张参考图或一段描述，教它认出你专属的分类**（比如你家的猫、特定手办）。

![智能分类](https://blog.siyuan.ink/static/img/53a883e3ea4057a7fa0aa6f6db1aabcd.02-classification.webp)

**3. 精准人物聚类 & 3D 足迹地图**

自动把同一个人的照片归档，支持多外观聚类（**戴眼镜和不戴眼镜分开拍也能认出是同一个人**）。带 GPS 信息的照片会自动点亮 3D 地球，连成你的旅行轨迹。

**4. 几个特别戳人的小功能**

- **月迹**：把你随手拍的月亮，按月相和农历日自动排成一条时间线（强迫症极度舒适）。
- **票夹**：自动识别火车票、机票并归档，和当天的旅行照片自动关联。
- **断舍离**：像刷卡片一样左右滑动清理废片，手滑删错了随时撤回。

## 二、 保姆级安装教程（.fpk 避坑指南）

**第一步：获取安装包**

- 官网下载页（选 `NAS / 服务器` → 飞牛 `fnOS · x86 · CPU · .fpk`）：<https://trailsnap.cn/download>
- GitHub Release 直达（`TrailSnap-0.21.0-fnos-x86.fpk`）：<https://github.com/LC044/TrailSnap/releases/tag/v0.21.0>

![下载页](https://blog.siyuan.ink/static/img/c38665720979da166636f6b233d4e844.05-download.webp)

**第二步：飞牛应用中心安装**

打开飞牛 **「应用中心 → 手动安装 → 从电脑上传」**，选中刚下好的 `.fpk` 文件，会弹出下面这个设置框：

![飞牛安装设置](https://blog.siyuan.ink/static/img/464cdad8d45ade99a1b1594aa90e9948.06-fnos-install.webp)

| 配置项 | 填写说明与避坑提示 |
| --- | --- |
| **端口** | 默认 `3180`，如果和现有服务冲突改一个就行 |
| **已有的照片目录（可选）** | 可以先留空，装好再加；也可以直接填现有照片路径 |
| **用户数据目录（必填）** | **务必选一个空文件夹**，用来存放索引数据库和配置 |

⚠️ **两个防踩坑要点：**

1. **目录绝对不能互相包含！** 比如你的照片在 `/vol1/1000/Photos`，那用户数据目录就新建一个平级的 `/vol1/1000/TrailSnap`，**千万别建在 `Photos` 文件夹里面**。
2. **默认只读挂载最安全：** 接入的照片目录默认是「只读」权限，软件绝对不会修改或删除你的原图。只有当你打算用它的「断舍离」或重命名功能直接操作 NAS 原文件时，才需要去改成读写。

> 💡 **老用户无痛迁移：** 如果你之前已经用 Docker 部署过，从 `0.21.0` 开始支持**直接迁移到 fnOS 原生安装包**，数据库和照片目录原地接管，不用重新扫图（文末附官方迁移文档）。

首次安装会自动拉取运行环境，等状态变成「可打开」后，点击打开创建管理员账号，之后局域网内任何设备访问 `http://你的飞牛IP:3180` 就能直接用了。

## 三、 怎么把 NAS 里的存量照片接进来？

刚进系统是空的，需要手动挂载一下你的图库目录：

1. **初始化接入**：进入行影集后台 **「设置 → 照片文件夹 → 重新检测」**，勾选你在安装时映射的目录，点击「添加选中的图库并扫描」。扫描和 AI 识别在后台静默运行，不影响前台正常看图。
2. **后期想加更多目录怎么办？**

   去飞牛 **「应用中心 → 已安装 → 行影集 → 应用设置 → 运行设置 → 编辑」**，在「新增照片目录」里填入完整路径，**多个目录用英文分号 `;` 隔开**，例如：

   ```text
   /vol1/1000/旅行;/vol2/1000/家庭
   ```

   保存后回行影集里点「重新检测」勾选即可。（注：在软件里移除目录只是取消挂载，不会删你硬盘里的原文件）。

## 四、 硬件占用与升级说明

- **硬件门槛低**：官方在 `fnOS V1.2.0800` 上实测通过，**纯 CPU 即可运行**，没有独显也能玩。当然，如果你的照片库有好几万张，或者想跑更复杂的本地大模型，大内存和核显/独显会让初次建索引的速度快很多。
- **安全提醒**：软件不会替代你的冷备份！如果开启了读写权限准备批量清理/重命名照片，**操作前一定先做好备份**。
- **无痛升级**：以后出新版，直接去应用中心「手动安装」上传新版 `.fpk` 覆盖即可，**不用卸载**，端口、数据、图库全保留，升级前还会自动备份数据库。
