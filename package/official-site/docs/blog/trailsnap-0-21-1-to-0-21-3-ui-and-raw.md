# 行影集 0.21.1 → 0.21.3：界面全部换新，相机 RAW 也能直接看了

**九天连发三版，从首页到足迹地图，行影集把界面彻底重做了一遍！**

过去九天里，「行影集（TrailSnap）」一口气连发了三个版本：**0.21.1（11月20日）、0.21.2（11月24日）、0.21.3（11月25日）**。

这一次不是常规的修修补补，而是一场由表及里的全面进化：不仅把整个 UI 界面推倒重做成了杂志与图鉴风格，还正式接入了相机 RAW 原片直出预览，更针对万级大图库做了深度的性能优化与桌面端硬件加速。

今天这篇文章，就带大家沉浸式体验一下更新后打开软件能立刻感受到的十大变化！

## 一、 告别冰冷列表，首页变身杂志风「影像手记」

以前打开行影集，映入眼帘的是一大片密密麻麻的照片墙；而现在，它变成了一本充满温度的**杂志式首页**。

![影像手记首页](https://blog.siyuan.ink/static/img/580184eb36081946fd2d46a404e3886a.01-home.webp)

*▲ 首页顶部「精选影像」轮播，演示站自动推送「那年今日」并配以诗意文案*

- **左侧「精选影像」大卡片**：自动轮播你的高光时刻，每张照片都会配上拍摄地点与一句恰到好处的文案。点击「打开影像」即可直达原图。
- **右侧「IN THIS ROLL」胶片卷**：像实体胶卷一样纵向排开，每一格都是某个特定日期的代表作（例如：*2023年11月26日 · 3年前 · 西安市*）。
- **底部三张核心入口卡**：整合了**足迹地图**（点亮走过的城市）、**一日一帧**（记录当下）与**回忆**（串联过往）。

轮播切换时伴随照片飞入与数字滚动的细腻动效。这绝非花架子，而是产品理念的转变——**现在的首页不再冰冷地统计“你有多少张照片”，而是在温柔地回答“今天值得看什么”。**

点击底部的「回忆」卡片，还会进入专属的记忆长廊：

![记忆页](https://blog.siyuan.ink/static/img/3faa37dd83dbf287110da80fa9bc717b.02-memories.webp)

*▲ 记忆页：上半部分按年份装订成「人生章节」，下半部分为图文并茂的「我的记忆」*

上半部分是按年份装订的「人生章节」；下半部分是具体的「我的记忆」，每一条都记录了时间、地点、照片数量，甚至还贴心地附上了一段由 AI 生成的回忆随笔。

## 二、 照片墙升级：按月分块 + 虚拟瀑布流，秒开不卡顿

这是 0.21.2 版本中最实用、体感提升最明显的一处改动。

![照片墙](https://blog.siyuan.ink/static/img/9a281baae7e30d3604c41460f74e9bc6.03-photos.webp)

*▲ 演示站照片页：近万张影像按天分组，右侧配有年份时间刻度尺*

底层加载逻辑迎来了三重进化：

1. **首屏秒开，拒绝转圈**：数据一到立刻上屏，再也不用盯着空白屏幕等整个图库算完，剩下的照片随滑动无感加载。
2. **按月分块加载**：滑到哪个月才加载哪个月的数据，不再一股脑把几年的照片全塞进内存。配合右侧的**年份刻度尺**，指哪跳哪。
3. **原比例虚拟瀑布流**：屏幕之外的照片自动回收释放内存；同时彻底告别强行裁剪成正方形的粗暴做法，横图、竖图全按原始比例错落排列，观感极佳。

## 三、 位置相册重做：把旅行足迹排成一本「摄影图鉴」

以往的位置页只是“一张地图加一串城市列表”，0.21.2 将其彻底重塑为极具高级感的**图鉴排版**。

![位置相册图鉴](https://blog.siyuan.ink/static/img/b68fff238fa864ff3bf5557cc9306474.04-location.webp)

*▲ 位置相册图鉴首页：大号宋体数字搭配主题色，宛如翻开一本实体摄影集*

页面抬头采用醒目的宋体大数字搭配主题色，视觉冲击力拉满：

- **核心数据一目了然**：去过 **52 座城市**、留下 662 帧影像，跨度 2010—2026；足迹覆盖率高达 **94%**，点亮 32/34 个省级行政区与 6 个国家。
- **视觉语言高度统一**：地图、时间轴、轨迹、统计、拼图、照片详情——这六大视图现在共用同一套抬头与数字排版。以前切来切去像在看不同的网页，现在则像在翻阅同一本精装书的六个章节。

## 四、 足迹地图支持 3D 地球与「时光回放」

早在 0.15.0 就已登场的 3D 足迹地图，在此次更新中也融入了全新的图鉴美学。

![3D 足迹地图](https://blog.siyuan.ink/static/img/69fcfa54e6140716b28991f86b8b6292.05-footprint.webp)

*▲ 3D 地球视图：点亮的城市之间由金色航线相连，右侧为「探索世界」数据面板*

在 3D 地球模式下，你去过的每一座城市都会在星球表面点亮，城市之间由璀璨的金色线条相连；右侧的「探索世界」面板则清晰列出了省份、城市、定位照片数以及热门打卡地排行。

最令人惊喜的是底部的**时光回放滑杆**：从「全部」一路拖动到 2026，你可以亲眼看着自己的旅行版图是如何一年年向外扩张的。点击播放键，轨迹会按拍摄时间顺序自动连线，仿佛在看一部专属于自己的旅行纪录片（右上角支持随时切换 **2D / 3D / 地球** 三种模式）。

## 五、 摄影党狂喜：相机 RAW 原片直接预览与高清查看

0.21.3 版本重磅新增的硬核能力！

过去，相机拍出来的 RAW 格式原片往往只能依赖 Lightroom 等专业软件查看。现在，你可以直接将 RAW 文件加入行影集图库，**日常预览与高清看图全部在行影集内一站式搞定**，甚至支持直接手动上传 RAW 文件。

对于习惯“手机随手拍 + 相机认真拍”的双修玩家来说，再也不用痛苦地维护两套相册系统了——手机 JPG 与相机 RAW 终于能在同一个时间轴里完美融合。

## 六、 整理工具箱进化：画面好不好，AI 直接打分

0.21.3 为自带的整理工具箱补齐了两项实用细节：

![工具箱](https://blog.siyuan.ink/static/img/68e4b6aea813208d526cd908e2ca6ed9.07-toolbox.webp)

*▲ 工具箱七大核心功能：涵盖去重、低质清理、元数据修正与批量整理*

- **画面质量量化打分**：在清理「低质量照片」时，系统会为每张照片标出 **0~100 的画面质量分**。删不删不再全凭肉眼纠结，看分数就能快速决策。
- **支持连续多轮清理**：清完一轮紧接着下一轮，无需反复退出重进；同时修复了此前相似照片分页时预览图可能错位的问题。

> ⚠️ **贴心提示**：工具箱中的整理、重命名与清理操作会直接作用于硬盘原文件。**动手整理前请务必做好数据备份**，任何管理工具都不能替代你的核心备份方案。

## 七、 智能分类与筛选面板重构，单手操作更顺手

0.21.1 对分类页和筛选面板进行了大刀阔斧的交互升级：

![智能分类](https://blog.siyuan.ink/static/img/2fb7fa000a0c2b8af0ddec801a2716e3.06-classification.webp)

*▲ 智能分类页：12 个大类采用玻璃胶囊设计，各类别数量清晰可见*

- **玻璃拟态胶囊卡片**：12 个智能分组一目了然，点击才会展开细分类别，告别信息过载。
- **所见即所得的筛选栏**：筛选面板改用「分段控件 + 已选胶囊」设计，当前生效了哪些条件一眼看清；移动端还将「重置」和「完成」按钮贴心地挪到了屏幕底部，单手操作毫无压力。
- **智能排序**：0.21.2 进一步优化了排序逻辑，筛选列表里的城市和类别会按你的使用频率自动排在前面，常去的地方一秒找到。

## 八、 万级大图库深度优化，丝滑度肉眼可见

分散在三个版本中的底层性能打磨，让拥有成千上万张照片的重度用户获得了质的飞跃：

- **SQLite 查询重构（0.21.3）**：重写了底层查询计划与表连接方式，分类检索与搜索响应大幅提速。
- **月迹页与朋友圈按需加载（0.21.2）**：复用农历换算格式化器，切换月份时仅加载当前可见区域，彻底告别卡顿。
- **外部图库移除加速（0.21.3）**：移除外部挂载目录不再干等，新增直观的实时进度条。

---

## 九、 桌面端黑科技：自动识别显卡 / NPU 硬件加速

针对 Windows 桌面版，0.21.1 引入了 **AI 加速包**，而 0.21.2 则让它彻底实现了「全自动适配」：

- **硬件自动调度**：软件会自动探测你的电脑配置——有 NVIDIA 独显就调用 **CUDA**，Intel 平台走 **OpenVINO**，配备 **NPU** 的新款笔记本还能直接调用 NPU 分担文本推理，图像识别与特征提取速度成倍飙升。
- **安全无感降级**：加速包采用按需下载（带进度条与签名校验），切换前自动检测环境兼容性；即便硬件不支持，也会自动平滑退回 CPU 模式并给出明确提示，绝不报错卡死。
- **新增 Token 用量统计面板**：支持按近 7 / 30 / 90 天统计各模型与场景的请求数、Token 消耗及缓存命中率，本地算力开销或在线 API 账单一目了然。
- **本地模型轻量化升级**：默认多模态模型升级为 **MiniCPM-V 4.7**，OCR 文字识别换用更轻巧的 **PP-OCRv6 tiny**，在保持高精度的同时大幅降低资源占用。

## 十、 两个提升幸福感的小细节

## 如何升级体验？

![官网下载页](https://blog.siyuan.ink/static/img/b65f7ee99b399790ff39f6344169fcf3.08-download.webp)

*▲ 官网下载页已同步更新至 v0.21.3，内置国内加速线路*

本次官网下载页也同步改版，新增了**自建镜像与多源测速**，桌面端下载器还支持断点续传。各平台升级方式如下：

- **桌面端**：打开软件接收应用内更新提示，或前往官网下载最新安装包覆盖安装。
- **飞牛 fnOS**：进入「应用中心 → 手动安装」，直接上传新版 `.fpk` 文件覆盖即可（**无需卸载旧版**，端口、数据目录与图库完整保留，升级前系统会自动备份数据库与配置）。
- **Docker 部署**：在安装目录执行 `./install.sh --upgrade` 一键升级。
- **手机 App**：在应用内直接检查更新即可。
