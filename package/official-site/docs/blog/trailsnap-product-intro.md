## 一张照片的困境

先说个真实的场景。

去年国庆，你去了趟西北。回来那天晚上，你躺在床上想找一张"车窗外是戈壁、日落打在挡风玻璃上"的照片。你打开相册，输入"戈壁"，没有。输入"日落"，出来 200 张，你翻到一半放弃了。

一周后你想写那趟游记，打开相册，发现你已经想不起具体哪几张照片值得用。

问题不是你不爱拍照。恰恰相反——**你拍了太多，而相册早就不是相册了，它是一个没人整理的仓库。**

云相册能解决"存得下"，但解决不了"找得到、串得起来"。照片被算法按"拍摄时间"排成一条永远往前的河流，而记忆是**跳跃**的：它按人、按地点、按画面、按情绪检索。

**行影集 TrailSnap** 想做的，就是把这条河流拦下来，重新编织成一张网。

![行影集官网 - 智能相册三大能力](https://blog.siyuan.ink/static/img/472300560d997c92acfb2d368726a39a.02-capabilities.webp)

*整理、查找、回顾——这是行影集最核心的三件事。*

## 它是什么：一个装在你自己电脑里的 AI 相册

先说清楚它**不是**什么。

它不是又一个云盘，不是又一个"AI 修图"工具，也不是一个需要你注册账号、上传照片到别人服务器的图片 App。

行影集是一个 **自托管（Self-hosted）的开源 AI 相册**：

- 照片**始终在你的硬盘、你的 NAS 上**
- 索引、识别结果、统计数据库，**也在你自己的机器上**
- 源码基于 **AGPL-3.0** 协议开放，GitHub 上 800+ Star
- 桌面版自带 AI 运行环境，**装完就能用**，不用折腾环境变量

> 用它的人说过一句很准的话：*「未来每个人（至少每个家庭）都有一个属于自己的 AI 数据中心，而相册是数据中心最重要的数据来源。」*

AI 相册，就是把这些瞬间**转化为有价值的记忆**的工具。

## 三大核心能力

### 01 智能分类 —— 让照片自己归位

打开行影集，你看到的不再是 `IMG_2847.jpg` 这种文件名，而是：

- **家人**：人脸识别 + 聚类，同一个人的照片自动成册
- **风景**：场景自动分类，夜景 / 美食 / 宠物 / 自拍各归各位
- **时间**：还能按年、按月、按日回看某一天

支持 iPhone、Vivo、OPPO、小米等手机的 **Live Photo（实况照片）**，缩略图 EXIF 元数据也能完整读取。

![行影集 - 时间轴浏览](https://blog.siyuan.ink/static/img/876ffdd8c3ddc4348895fff52ef8713c.site-timeline.webp)

*丝滑的时间轴滚动，几十年的照片一眼扫过。*

### 02 以文搜图 —— 用"记得的画面"找照片

这是我觉得最爽的一个功能。

搜索框里打一句话：**"海边看日落的照片"**。搜索结果直接给你标出「海边 / 日落 / 傍晚」这些语义线索——它读懂了你描述的那个**场景**，而不只是在匹配文件名。

还能叠加维度：结合**人物 + 时间 + 地点**一起找。

![行影集 - 以文搜图](https://blog.siyuan.ink/static/img/95fe4fb5c09327ee8483aaa0fa9b6e27.07-demo-search.webp)

*在线演示站实测：搜"海边日落"，50+ 结果精准命中。*

### 03 足迹地图 —— 在地球上回望你的旅程

这是行影集最有"作品感"的功能。

照片带 GPS 信息就能被点亮。你会看到：

- **3D 地球**：拖动地球、缩放视角，照片钉在真实的城市坐标上
- **城市点亮**：去过的省 / 市 / 区县，自动统计排名
- **5A 景区**：内置 5A 景区识别，记录你打卡过的名山名胜
- **足迹时间轴**：按年份拖动，2010 → 2026 一路回放
- **轨迹视图**：把一段时间的地点连成线，还原你当时的移动路线

![行影集 - 足迹地图](https://blog.siyuan.ink/static/img/c173fae9ef8216748f978b22bfcdd09a.03-journeys.webp)

*3D 足迹地球。32 个省份、52 座城市、579 张足迹照片——这是数据自动算出来的。*

## 还有一些"只有真爱照片的人才会做"的功能

### 人生章节 · 月迹 · 票夹

三个很私人的设计：

- **人生章节**：一天一页，照片和文字留在一起，把散落的生活重新装订成一个日记本
- **月迹**：随手一拍的月亮也有自己的时间线，按月相回看——从渐盈到满月，收藏那些曾经抬头的夜晚
- **票夹**：火车票、机票、电影票、演唱会门票自动识别归档，留下路线、日期与行程

### 断舍离：给相册减减负

向右保留，向左丢弃。像 Tinder 一样滑，但滑掉的是你不再需要的照片。

它还内置了相似照片检测、**基于哈希值的重复照片清理**、以及按 AI 评分做的低质量清理——真正把"整理"这件事做完了。

### 票据识别（OCR 引擎）

官方说这个 OCR 引擎**专为火车票识别做了深度优化**：平整扫描件和带背景的翻拍照片都能保持高识别率，车次、日期、车站、座位号、票价直接抽成结构化 JSON，还能导出成仿真纸质火车票（红票 / 蓝票样式）。

### 年度报告

照片墙、照片日历、城市榜单、景区榜单、行程时间轴、线路里程、四季分布、年度最佳照片——把一年做成一份**能直接发朋友圈**的作品。

![行影集 - AI 分析与叙事](https://blog.siyuan.ink/static/img/e38e25ce6baebfca9b0b60d2bd0d21db.site-AI-narrative.webp)

*AI 帮你把照片写成有叙事感的文字，不只是打标签。*

### 那年今日

每年这一天，AI 挑出往年今天最有回忆价值的那几张照片推给你。

这个功能的存在意义就是——**对抗遗忘**。

## 怎么装起来？比你想的简单

### 方案 A：桌面版（推荐个人用户）

Windows 10/11、macOS（Apple Silicon）、Linux 都能装。

**关键点：桌面安装包已经内置了 AI 运行环境**，人脸识别、OCR、图片分类、语义检索和本地大模型的模型文件按需下载。不用你手动配 Python、配 CUDA、配数据库。

步骤就四步：启动 → 添加照片目录 → 等扫描索引 → 在"AI 模型管理"里建分析任务。

### 方案 B：Docker 部署（推荐 NAS / 家庭服务器）

一行脚本，前端、后端、PostgreSQL、AI 服务一次拉起：

```bash
# Linux / macOS / WSL2
curl -fsSL https://trailsnap.cn/install.sh | bash

# Windows PowerShell
irm https://trailsnap.cn/install.ps1 -OutFile install.ps1
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

脚本会引导你填照片目录、访问端口、时区和 AI 模式，生成 `.env` 和 `docker-compose.yml`，拉镜像并做健康检查。默认地址 `http://<服务器IP>:3180`。

**AI 加速三选一**：通用 CPU / NVIDIA GPU（CUDA）/ Intel OpenVINO（核显、NPU 友好）。切换模式时数据库、模型缓存和照片目录都不会丢。

![行影集 - 安装流程](https://blog.siyuan.ink/static/img/b1cb6292d395d73d861ecb3161ada608.11-install.webp)

*官网把安装拆成了清晰的四步：选版本 → 接照片 → 配模型 → 开始浏览。*

### 方案 C：NAS 一键包

绿联、极空间、飞牛 OS 都有现成教程，飞牛还提供 `.fpk` 格式安装包，在应用中心手动安装、填端口和照片目录就能跑。同一局域网内的手机、平板、电脑，用浏览器就能访问同一份图库。

### 方案 D：手机 App

TrailSnap Android App 用 Capacitor 构建，是 Web 版的原生容器。装好后扫码连自己的服务器，地址就是 `http://192.168.1.10:3180`，**不用加 `/api`**。局域网内手机、平板、多台电脑共享同一图库。

![行影集 - 下载页](https://blog.siyuan.ink/static/img/99c07617b03020c85d6e1c8687244339.09-download.webp)

*下载页会自动识别你的系统并标出对应安装包，还提供备用镜像地址。*

## 关于隐私，官方说得很直白

> *「TrailSnap 是自托管应用：照片、数据库和账号数据保存在你部署的服务器或 NAS 上。项目不会因为你安装了 TrailSnap 而自动接收你的照片。」*

具体的数据边界：

- **本地模型 / 本地 LLM** → 推理数据全程留在你的设备和服务器内
- **接 OpenAI、Ollama 等远程服务** → 发送哪些文字图片取决于你启用的功能和服务商设置，官方也提醒你先读隐私条款，别把敏感照片喂给不受信任的服务
- **Agent Token** 只授予必要范围，泄露立即撤销

还有一句实在提醒很值得抄下来：

> **桌面版不会替代你的照片备份。首次使用批量整理、重命名或清理功能前，请先备份图库。**

毕竟这是个会**动你文件**的工具。用它之前，先按一次 Ctrl+C。
