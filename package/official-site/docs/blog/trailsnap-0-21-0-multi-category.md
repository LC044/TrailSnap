# 行影集 0.21.0：照片终于不再只能属于一个分类

*一张雪山，同时是风景、是湖泊、是山，也是开阔风景*

行影集 0.21.0 带来全新的智能 CLIP 照片分类。一张照片可以同时带上多个分类，每个分类都带独立置信度；内置目录逐类校准过识别阈值；你还能用一段文字或几张参考图，教它认识你自己的分类。



以前用相册分类，逻辑很简单：**一张照片，一类标签。**

拍到雪山的照片，就归到「雪山」；拍到湖水的，归到「湖泊」。

但现实不是这样的。**一张雪山顶着湖水的照片，同时也是一片风景，也是一座山。** 你硬要把它塞进一个抽屉，就必然要在某些抽屉之间反复横跳。

行影集 0.21.0 把这件事重做了。

### 一张照片，可以同时是很多种东西

打开演示站的「分类」页，随便点开一张照片，看它的信息面板：

![多标签](https://blog.siyuan.ink/static/img/4e5c83fa34c1341ac11c39b036f25a6d.06-multitag.webp)

*一张雪山湖泊的照片，标签栏里同时挂着五个分类：风景、湖泊、山、雪山、开阔风景。点开任意一个都能进到对应的相册。*

**风景、湖泊、山、雪山、开阔风景——五个分类，同一张照片。**

每个分类背后还带一个置信度：这张照片「风景」0.99，「湖泊」0.43，「山」0.42，「雪山」0.42，「开阔风景」0.41。

主分类拿高分，衍生分类拿辅助分。你按「山」去找，能找到它；按「湖泊」去找，它也在。

行影集在底层给每个分类配了**独立的识别阈值**——不同类别的清晰度本来就不一样，用一把尺子量所有类别必然一头紧一头松。所以阈值是分类自己说了算：

![阈值](https://blog.siyuan.ink/static/img/959bc08fffde1f69e2685befc5857b73.08-threshold.webp)

*高级设置里可以按模型单独调阈值——「分数是照片与分类特征的相似度。提高阈值会更严格；使用参考图后建议重新标定阈值」。*

### 内置目录：12 个分组，173 个分类

打开「分类规则」，能看到完整的内置目录：

![分类目录](https://blog.siyuan.ink/static/img/a71d3d758921420bb9e92a79a62b080c.01-classification-groups.webp)

*演示站的分类总览：人物、自然风景、建筑 / 场所、美食饮品、动物、植物花卉、物品 / 静物、交通出行、活动 / 事件、文档 / 截图 / 资料、插画 / 漫画 / 表情包，外加一块 YOLO / 自定义分类。演示站当前已启用 173 个分类。*

点开规则面板，能看到每一个分类的名字、张数，以及它的开关：

![规则面板](https://blog.siyuan.ink/static/img/168f18f72a5b07162c9447294535340b.02-classification-rules.webp)

*「分类规则」面板：一行一句话写着「保留原有 YOLO 分类，按文字和参考图片增加 CLIP 标签」。每个分类后面跟着张数和「自动分类已开启」，整组还能单独停用。*

注意面板顶部那句话：**「保留原有 YOLO 分类，按文字和参考图片增加 CLIP 标签。」**

这是这次升级的关键设计：**老的分类不扔，新的分类叠加上去。** 你原来攒下的标签还在，只是照片现在可以多带几个。

分组里的每个分类点进去，就是一个按时间排好的相册：

![雪崩相册](https://blog.siyuan.ink/static/img/d38f1949b692adeb86031722532cc8fe.05-group-nature.webp)

*「自然风景」分组：点开是 20 个细分分类，夜景、天空云彩、日出日落、山、雪山、湖泊、河流、瀑布、海滩、沙漠、草原、湿地、森林、火山……往下翻到底。*

「雪山」分类在演示站里有 108 张照片，按年月排开：

![雪山相册](https://blog.siyuan.ink/static/img/1cb09280533629c4551dd0e760b5f87e.07-snow-album.webp)

*「雪山」分类：108 个项目，从 2026-11 一路排到 2015，每一张都是模型自己认出来的。*

### 准确度是怎么来的：每个分类都被单独校准过

内置目录不是拍脑袋列的。官方更新日志里的原话是——**「内置 11 组 166 类校准目录，支持自定义文字描述与参考图裁剪规则，先预览再应用，可对历史照片重新计算。」**

行影集对**每一个分类**都做了一遍校准：抽样人工标注正样本和负样本，用模型给整库照片打分，然后给这个分类定一个专属阈值。

校准记录就挂在 API 里。以「自拍」和「雪山」为例：

- **自拍** —— 状态 `reviewed`（已复核），阈值 0.43。人工标了 9 个正样本、7 个负样本，训练集上 8 个正样本全部命中，零误判。
- **雪山** —— 状态 `limited`（样本有限），阈值 0.415。标了 11 个正样本、7 个负样本。
- **夜景** —— 阈值 0.43，状态 `limited`，标了 7 个正样本、11 个负样本。

整批评分用了 **75041 张照片**，方法名 `visual-stratified-f0.5-grid0.005-v2`，校准日期 2026-11-12。

**每个分类的阈值都是单独定的，因为每个分类的难度本来就不一样。** 演示站这 173 个分类一共用了 18 档不同的阈值，从 0.385 到 0.48 不等。

而「文字描述」这一层，是校准的另一半：

```json
"雪山": {
  "descriptions": [
    "一张雪山的实拍照片",
    "山峰和山坡覆盖积雪",
    "白色雪峰与周围山脉"
  ],
  "thresholds": { "chinese-clip-ViT-B-16": 0.415 }
}
```

每一类都配了不止一句描述——因为「雪山的实拍照片」是废话，「山峰和山坡覆盖积雪」才是模型真正能用的特征。

### 自定义分类：教它认识你的世界

内置目录再全，也总有它没有的。

**「露营」「钓鱼」「我家的猫」「公司工位」「毕业典礼」**——这些只有你需要的分类，可以自己建。

点「新建分类」：

![新建分类](https://blog.siyuan.ink/static/img/288528bc78ee4475dc07f3aae77a7ca8.03-new-category.webp)

*「新建分类」弹窗：分类名称、展示分组、文字描述（最多 5 条）、参考图片（0/5）、匹配严格程度、自动分类开关，以及可展开的模型匹配阈值。*

它给了你两种教法，**至少填一种就行**：

### 用文字描述

最多 5 条，每条不超过 100 字。写你脑子里的画面：

![填好描述](https://blog.siyuan.ink/static/img/340c1d270d9e1befbaa848f4fa867b1a.04-new-category-filled.webp)

*填好「雪山」和一段描述：「被雪覆盖的山峰、滑雪场、冬天去过的高山、照片里有大片积雪的山」。*

弹窗里写得很清楚：**「文字和参考图片至少填写一种。每条文字、每张图片等权合并，形成同一个分类特征。」**

### 用参考图片

最多 5 张，20 MB 以内。可以**上传**，也可以**直接从你的图库里挑**。

关键是这一句：**「可逐张截取目标区域，支持 20 MB 以内的图片，裁剪仅用于分类，不修改原图。」**

你有一张构图很好的露营照，但主体只占中间一小块？那就把那块框出来当参考——**只用来学特征，你的原图不动。**

### 三个档位

匹配严格程度有「宽松 / 标准 / 严格」三档：

- **宽松** —— 宁多勿漏，可能会多标几张
- **标准** —— 均衡，默认就是这个
- **严格** —— 宁缺勿滥，只标最有把握的

### 先预览，再应用

填完点「预览结果」，先看看它会挑出哪些照片，满意了再保存。**不用赌。**

新建并启用后会自动对全部历史照片分类——所以不用为了一个新分类重新导入一遍图库。

界面上还有一句：**「该分类样本有限或使用自定义规则，请标定后调整阈值。」** 意思是：你自己定义的分类，刚建好的时候阈值可能需要自己微调一下。

### 这次更新还带来了什么

0.21.0 不只是分类这一件事：

**全量照片清理** —— 重复与相似照片清理改成后台扫描，不再有数量上限。扫描可随时停止并从检查点继续；相似扫描分「快速 / 完整」两种模式；结果分页展示参考图，支持跨页选择和保留项复核，确认后才进回收站，还能导出 CSV 清单。

**人物「查找此人的更多照片」** —— 「重新扫描人脸」升级成了这个。支持自定义匹配阈值和移出阈值，候选按相似度排序。相似人脸查找新增高级选项，档位也调成了严格 / 普通 / 宽松。

**飞牛 fnOS 迁移** —— 从 Docker 部署可以直接迁到飞牛安装包，数据库和照片目录直接接管，不用重新导入。

**车票识别扩展** —— 支持 N/V 字头车次和压缩日期格式。

还有一批优化和修复：任务事件合并批量推送（侧栏和任务管理页共享状态刷新）、工具箱流程简化、相似人脸候选排序，以及四个 bug 修复——包括「删除照片后人物列表照片数量不更新」和「人物详情页时光线标签被时间轴轨道遮挡」。

### 怎么更新

安装包已经发布：

- **Windows**：EXE 安装包
- **macOS（Apple Silicon）**：DMG 安装包
- **Linux（x64）**：AppImage / DEB
- **飞牛 fnOS**：x86 安装包
- **Android**：APK（调试版）

在官网下载页选你的设备直接下就行，桌面版应用内也能检查更新。

Docker 部署的照旧拉镜像。已有实例升级前记得备份数据库和照片目录。

**桌面版内置完整的 AI 运行环境**，不用自己配 Python、CUDA、数据库。装好 → 添加照片目录 → 建索引任务。跟以前一样，第一遍索引要花时间。

**不想折腾的话，演示站可以直接点开看**——上面这些截图全部来自 `demo.siyuan.ink`，新分类功能已经部署在上面，不用注册、不用下载。

### 照片始终在你自己的硬盘上

行影集是**开源自托管**的软件。照片、数据库、账号，全都在你自己的电脑或 NAS 上。

**分类这件事尤其如此。** 模型在你机器上跑，标签在你机器上存，连判断"这张照片算不算雪山"的过程都不出家门。

你只是在描述"我要什么"——照片是什么、怎么分、存在哪，全是你说了算。

### 最后

相册分类这件事，从"一个标签"变成"多个标签"，听起来只是多贴几张标签。

但真正变的是**你找照片的方式**。

以前你问：「我的雪山照片呢？」——相册在一个抽屉里翻。

现在你问：「有哪些照片既是山、又是湖？」——相册直接给你，因为那张照片本来就同时是两者。

**照片不需要被塞进一个抽屉。它是什么，就是什么。**
