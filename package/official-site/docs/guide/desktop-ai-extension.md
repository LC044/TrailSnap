# 桌面版 AI 扩展使用说明

TrailSnap 桌面版将 AI 运行环境与基础安装包分开发布。这样不使用 AI 的用户无需下载大型依赖，需要时再安装一次与你的操作系统匹配的扩展包即可。

::: info Docker 用户
Docker 版的 AI 服务已经由 `docker-compose.yml` 管理，不需要安装桌面 AI 扩展。本文仅适用于 Windows、macOS 和 Linux 桌面客户端。
:::

## 扩展提供的能力

- 人脸检测、识别与聚类
- OCR 文字识别与票据识别
- 图片分类与智能标签
- 图片向量与语义检索
- 本地多模态大模型能力（另需 `llama-server`）

AI Sidecar 只会在相关功能首次调用时启动，空闲后自动停止。卸载扩展不会删除原始照片、独立模型或分析结果。依赖扩展的任务保留为“等待安装 AI 扩展”，重新安装后自动继续；用户主动暂停的任务保持暂停。

## 在线安装（推荐）

1. 先安装并启动 TrailSnap 桌面版。
2. 打开“设置 → AI 扩展包”。
3. 找到适合当前平台的扩展，点击“下载并安装 AI 扩展”。
4. 等待下载、校验和安装完成。安装过程中不要退出客户端。
5. 在同一页面确认扩展显示“已安装”，再创建人脸、OCR、分类等任务。

清单在线访问失败时，可点击“检查更新”；满足 Server 最低支持版本的已安装扩展仍可使用，低于最低版本的任务等待更新。

## 检查与下载更新

启动时读取 Server 最低支持的 AI 扩展版本，并获取当前 Server 同版本 Release 中的清单，也可点击“检查更新”。页面显示客户端、Server、最低支持版本、操作系统与架构。
已安装扩展版本不低于 Server 最低支持版本时继续使用，不自动升级或降级；低于最低版本时自动下载与当前 Server 同版本的扩展。未安装时仍由你选择安装。
最低支持版本由 Server 发布时声明；清单只提供平台附件下载信息，不包含远端强制更新规则。

已安装扩展的更新也会显示进度、暂停、重试和错误。兼容旧扩展在下载期间可继续使用；替换前暂停新任务派发，等待在途推理、结果提交与模型下载结束。
维护期间任务显示“等待 AI 扩展更新”，等待不会消耗失败重试次数。完成后自动继续，主动暂停不变；校验或替换失败保留旧扩展。
明确不兼容且暂无兼容附件时保持等待，使用官方下载页或离线导入处理，不会循环下载。

## 离线导入

1. 在扩展页面点击“手动下载”；附件直链及文件名对应当前平台和 Server 同版本。清单或附件不可用时，使用“官方下载页”打开 [GitHub Releases](https://github.com/LC044/TrailSnap/releases)。
2. 下载与当前平台匹配且支持当前客户端、名称包含 `TrailSnap-AI` 的 `.tar.gz`：Windows x64 选 `win32-x64`，macOS Apple Silicon 选 `darwin-arm64`，Linux x64 选 `linux-x64`。扩展可能位于历史 Release，不必与客户端版本相同。
3. 不要解压或修改文件。
4. 在“设置 → AI 扩展包”点击“离线导入”，选择下载的文件。
5. 客户端验证清单、平台与校验信息后完成安装。

::: warning 平台必须匹配
扩展包包含原生可执行文件，不能跨操作系统或 CPU 架构使用。只从 TrailSnap 官方 GitHub Release 下载。
:::

## 本地大模型与 llama.cpp

人脸、OCR、分类和语义检索不需要额外安装 `llama-server`。只有使用内置 MiniCPM 本地多模态模型时才需要 llama.cpp 运行时。

- Windows：在扩展页面点击“一键安装”。TrailSnap 会直接从 llama.cpp 官方 GitHub Release 下载并校验运行时，不要求电脑安装 winget。
- macOS：在扩展页面点击“一键安装”（需要 Homebrew）。
- Linux：自行安装或编译 `llama-server`，确保它位于系统 `PATH` 中，再重启 TrailSnap。

```bash
# macOS
brew install llama.cpp
```

## 扩展与“大模型连接”的区别

桌面 AI 扩展提供人脸、OCR、向量等本地 AI 运行能力；“设置 → AI 相关配置”中的大模型连接用于配置 OpenAI、Ollama 等对话或图片理解接口。两者可以独立使用。第三方模型的配置方法参见 [AI 大模型设置](/docs/guide/settings/aisetting)。

## 常见问题

- **下载失败或清单不可用：** 检查能否访问 GitHub Release，点击“检查更新”重试，或使用离线导入；清单失败不会显示“已是最新”。
- **安装后仍提示 AI 不可用：** 确认扩展为“已安装”，重启 TrailSnap。仍失败时查看应用数据目录 `logs` 下的 `ai.log` 和 `ai.err.log`。
- **更新或卸载：** 等待在途任务和模型下载结束后再停止 Sidecar；维护期间不能重复安装、卸载或离线导入。
