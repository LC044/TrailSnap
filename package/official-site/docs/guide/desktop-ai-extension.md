# 桌面版内置 AI

行影集桌面安装包已包含人脸、OCR、票据识别、分类、语义检索和本地大模型所需的 AI 程序，无需另行安装扩展或配置本地服务地址。

1. 安装并打开行影集。
2. 在“设置 → AI 模型管理”查看所需模型。模型按需下载，下载完成后相关任务自动继续。
3. 在“关于行影集”统一检查和安装应用更新。已下载模型和照片保留。

AI 程序首次使用时自动启动，空闲后释放资源。本地大模型所需推理依赖也由应用自动准备；首次使用需要联网，体积较大的模型需要等待下载。

旧版本用户直接升级完整应用即可，已有模型继续使用。无需先卸载旧 AI 扩展，也无需重新导入扩展压缩包。

Docker 独立部署继续使用其原有服务和地址配置。
