# 桌面版内置 AI

行影集桌面安装包已包含人脸、OCR、票据识别、分类、语义检索和本地大模型所需的 AI 程序，无需另行安装扩展或配置本地服务地址。

1. 安装并打开行影集。
2. 在“设置 → 本地识别模型或大模型与文案”查看所需模型。模型按需下载，下载完成后相关任务自动继续。
3. 在“关于行影集”统一检查和安装应用更新。已下载模型和照片保留。

AI 程序首次使用时自动启动，空闲后释放资源。本地大模型所需推理依赖也由应用自动准备；首次使用需要联网，体积较大的模型需要等待下载。

旧版本用户直接升级完整应用即可，已有模型继续使用。无需先卸载旧 AI 扩展，也无需重新导入扩展压缩包。

Docker 独立部署继续使用其原有服务和地址配置。

## 使用 GPU 或 OpenVINO 加速

桌面版默认使用内置 CPU。在 **设置 → 本地识别模型 → 推理设备** 查看当前实际设备；Windows x64 用户可以下载 **NVIDIA CUDA** 或 **Intel OpenVINO** 加速包。

1. 点击“下载加速包”。应用会自动选择可用加速源，展示进度，并校验完整性与发布签名；失败可重试，当前设备继续可用。
2. 下载完成后点击“使用此设备”。OpenVINO 可以选择 CPU、GPU 或 NPU，设备需要对应硬件和驱动支持。
3. 应用等待正在执行的 AI 请求和模型下载结束后，验证并切换设备。验证失败会恢复 CPU，并显示原因。

CUDA 需要兼容的 NVIDIA 显卡驱动；无需另装 Python、CUDA Toolkit 或 PyTorch。各已加载模型的后端与回退原因可在“各模型运行状态”查看。此设置用于本地识别模型，不改变本地大模型的推理设备。

升级保留模型、加速包和设备选择。加速包需要匹配客户端版本；旧包不兼容时使用 CPU，并提示下载当前版本。其他桌面平台继续使用内置运行时。
