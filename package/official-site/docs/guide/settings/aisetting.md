# AI 大模型设置

::: tip 桌面版用户
本页配置对话与图片理解使用的大模型连接。桌面版已内置 AI 运行环境，识别模型按需下载，参见[桌面版内置 AI](/docs/guide/desktop-ai-extension)。
:::

## 内置连接

TrailSnap 内置了 AI 连接功能，开箱即用。内置连接使用 MiniCPM-V-4_6-Q4_K_M 多模态模型，支持图片内容理解、标签生成等视觉任务。

内置连接在 **设置 → 大模型与文案 → 大模型连接与任务配置** 页面中显示，带有"内置"标识。**内置连接不能删除，服务地址和密钥由系统管理**。

如果需要使用第三方 API，可以添加新的连接。

## 添加连接

点击 **设置 → 大模型与文案 → 大模型连接与任务配置** 可以添加新的大模型连接。

1. 点击**添加连接**，选择 OpenAI 兼容接口，填写 Base URL 和 API Key。Ollama 等兼容服务使用其 OpenAI 兼容地址。
2. 点击**获取模型列表**并添加所选模型，或点击**手动添加模型**；每个连接至少需要一个模型。
3. 在弹窗中保存连接，再选择对话和智能分析所用模型，并点击**保存大模型配置**。

自动生成朋友圈文案与高级提示词位于同一页面；启用定时生成需要管理员权限。人脸识别、OCR 等服务地址和模型位于**设置 → 本地识别模型**。

## AI对话配置

点击 **设置 → 大模型与文案 → AI 对话默认配置** 可以配置AI对话（AI 助手）默认使用的模型。

## 大模型智能分析配置

点击 **设置 → 大模型与文案 → 大模型智能分析配置** 选择要使用的连接和模型，用于图片内容理解、标签生成等视觉任务。该任务比较简单，使用小模型即可完成。

涉及隐私问题需谨慎使用各个平台提供的云模型，推荐使用ollama本地部署qwen3.5:4b模型，或者使用`vllm`等本地大模型服务。

```bash
ollama run qwen3.5:4b
```

- Base URL: 视觉大模型的API基础URL，例如 `http://127.0.0.1:11434/v1`
- API Key: 视觉大模型的API密钥，本地ollama可以填写：`empty`
- Model Name: 视觉大模型的名称，例如 `qwen3.5:4b`

### 创建处理任务

设置完成之后可以点击“设置 → 后台任务 → 大模型智能分析”，选择`强制重做此项`或者`执行缺失任务`，开始分析照片（为了节省资源，分析的时候会自动略过**截图**）。

### 查看分析结果

1. 点击"工具箱-低分清理"，之后会显示所有AI分析完成的照片，按评分排序。
2. 点击照片，会弹出照片详情页，点击右上角选择"查看AI分析结果"即可显示该照片的AI分析结果。
3. 首页的"那年今日"模块，用户可以查看往年今天的照片（如果有的话），按图片评分排序并显示AI生成的照片文案。
