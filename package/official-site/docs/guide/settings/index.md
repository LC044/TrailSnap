# 设置指南

打开行影集的**设置**，按用途选择需要管理的项目。部分全局选项仅管理员可见。

<span id="主要配置项"></span>

## 我的设置

- **个人资料**：修改头像、昵称与账号信息。
- **外观与浏览**：切换明暗模式、主题色和打开照片时是否加载原图。这些偏好保存在当前设备，自动保存；默认跟随系统外观，首次使用优先加载预览图，仍可手动查看原图。
- **外部工具授权**：管理供 MCP、CLI 等工具使用的[访问令牌](./tokensetting.md)。

## 照片与图库

- **照片文件夹**：接入已有[照片文件夹](./directories.md)，管理自动扫描、回收站保留时间和图片生成质量。定时扫描默认关闭，启用后按服务器时区运行；新安装的回收站默认保留 30 天，已保存的设置以实际值为准。
- **连接手机 App / 手机备份**：下载或连接手机 App，并在支持的平台管理手机备份。
- **地图与地点**：配置[地图 API Key 和离线地点数据](./mapsetting.md)。

## 智能功能

- **本地识别模型**：查看识别服务地址、本地人脸和文字识别等模型，以及人物识别高级参数。桌面版的识别服务由应用管理。
- **大模型与文案**：管理[大模型连接](./aisetting.md)、默认模型和提示词，以及管理员可配置的自动生成文案。

## 管理与维护

- **成员与注册**：管理员管理成员并控制是否开放注册。
- **后台任务**：查看处理进度、失败详情和后台处理性能。
- **高级维护**：管理索引、进入性能测试，或导入导出当前账号的配置。导出的配置可能包含密钥；它不包含照片或服务器全局设置，请妥善保管。

<span id="配置文件"></span>

推荐通过设置页面管理配置。个人偏好、当前账号配置和管理员全局设置的作用范围各不相同，具体以页面提示为准。
