# 常见问题

## 安装部署问题

1. 支持哪些部署方式？

当前面向用户的部署方式是 Docker Compose。源码运行主要用于开发贡献，不作为日常部署路径；请先安装 Docker 环境。

2. 支持哪些平台？

目前支持Windows、macOS、Linux平台。支持x86架构和arm架构。

## 扫描、任务与照片

1. 首次扫描很久没有完成，是否正常？

首次扫描和 AI 分析耗时取决于照片数量、硬盘速度和模型配置。先在任务页面确认任务是否仍在运行，并查看服务日志。建议用小目录验证流程后再导入完整图库。

2. 为什么扫描不到照片或提示没有权限？

确认宿主机照片目录真实存在、Docker 已挂载该目录、服务具有读取权限。若要使用整理、重命名或清理工具，还需确认写入权限。详见[部署前检查](/docs/guide/preflight)。

3. 可以直接删除或移动照片文件吗？

建议通过 TrailSnap 的功能操作，或在变更后重新扫描。对照片目录进行大规模移动、重命名或删除前，应先备份。

## 手机与网络

1. 手机无法连接服务器怎么办？

确保手机和服务器在同一局域网，使用服务器的局域网 IP 而非 `localhost`；再检查 Docker 端口映射、系统防火墙和 Wi-Fi 是否开启了 AP 隔离。Android App 的地址填写说明见[移动 App 使用指南](/docs/guide/mobile-app)。

## 备份与升级

1. 更新前需要做什么？

更新前备份照片目录与 PostgreSQL 数据库，并阅读[更新日志](/docs/guide/changelog)。不要只备份其中一类数据。

2. 如何安全地使用外部 AI 或 Agent Token？

仅授予必要权限，不要公开 Token；通过公网访问时使用 HTTPS。完整说明见[数据、隐私与备份](/docs/guide/data-safety)。
