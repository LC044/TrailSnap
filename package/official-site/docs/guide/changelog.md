# 更新日志

## 2026-06-27 (0.5.0)

### 新增功能

- 新增**用户昵称与头像**设置，个人资料更个性化
- 新增**朋友圈布局模式**，以时间流方式浏览照片，还原社交相册体验
- 新增**照片情绪与色彩分析**功能，自动识别照片情绪与主色调
- 新增**照片批量导出**功能，支持自定义命名模板（如 `{date}_{location}_{seq}`）
- 新增**照片位置编辑**功能，支持单张调整与批量修改照片的拍摄位置
- 新增**位置统计视图**，按地点汇总照片数量与分布
- 新增**任务通知系统**，通过 SSE 实时推送任务进度，侧边栏集中管理任务
- 新增**快捷键管理**（`useHotkeys`），统一键盘交互体验
- 新增照片页直接上传入口与**反馈页面**
- 新增服务**健康检查接口**，便于部署与监控
- 新增 **Windows 一键安装脚本**，简化部署流程
- 新增**文件夹过滤**功能，扫描外部图库时自动跳过 NAS 索引目录（如 `@eaDir`、`#recycle`），避免照片重复统计，并支持一键清理已索引的相关照片

### 优化功能

- 优化导航栏与全局搜索体验
- 离线地图设置新增刷新按钮，优化 UI 与 API 返回字段
- 合并上传任务为 `PROCESS_BASIC`，简化任务流程
- 升级安装脚本至 v1.2.0，优化安全性与交互体验

### Bug 修复

- 修复 `PhotoLightbox` 组件卸载时资源未释放和滚动锁定的问题
- 修复 Windows 一键安装脚本执行与中文乱码问题
- 移除情绪日历页面

| 添加外部文件夹 | √ | 可以添加外部文件夹作为数据源，TrailSnap 会自动扫描并索引其中的照片和视频。 |
| live photo | √ | 支持vivo、oppo、小米等手机 |
| **时间轴** | √ | 丝滑的时间轴滚动效果。 |
| 在地图上查看照片 | √ | 可以在地图上查看所有上传的照片，点击照片可以查看详情，也可以按省、市、区单独查看（支持列表视图和地图视图）。 |
| **点亮的城市** | √ | 查看所有上传的照片中出现的城市，点击城市可以查看该城市的所有照片。 |
| **去过的景区** | 开发中 | 统计去过的5A级景区，点击景区可以查看该景区的所有照片，也可以自定义景区位置，自动筛选在景区范围内的照片。 |
| 人脸识别 | √ | 支持识别照片中的人物，自动添加人物标签。 |
| 场景智能分类 | √ | 支持根据照片中的场景自动分类，例如：夜景、宠物、美食、自拍等。 |
| 智能搜索 | √ | 支持根据照片中的人物、画面内容、时间等进行搜索。 |
| 标签 | √ | 支持手动添加和删除标签，也可以根据 AI 识别结果自动添加标签。 |
| 条件相册 | √ | 支持根据标签、场景、人物、地点等条件筛选照片，生成自定义相册。 |
| 智能相册 | √ | 支持根据照片中的内容自动生成相册，例如：“我和女朋友在海边的自拍”等。 |
| **车票识别** | 开发中 | 支持识别照片中的火车票和行程单，自动提取行程信息。 |
| **年度报告** | 开发中 | 自动生成2025年的出行统计报告，包括照片墙、出行城市、出行景点、行程时间轴、线路里程等。 |
| **旅行日志** | 待开发 | 支持用户手动输入或 AI 识别出的行程信息，生成旅行日志。 |
