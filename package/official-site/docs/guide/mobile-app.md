# 移动 App 使用指南

TrailSnap App 是 Web 版的移动端原生容器，使用 Capacitor 构建。它不会提供公共云端服务，
而是连接你自己部署的 TrailSnap 后端。因此，在安装 App 前需要先完成
[TrailSnap 服务部署](/docs/guide/install)。

::: warning 预览版本
移动 App 目前优先适配登录、相册浏览、搜索、设置等基础功能。部分原生能力仍在开发中，
建议保留浏览器访问方式作为备用。
:::

## Android 安装

1. 打开项目的 [GitHub Releases](https://github.com/LC044/TrailSnap/releases)。
2. 找到名称以 `TrailSnap App` 或标签以 `app-v` 开头的版本。
3. 在 **Assets** 中下载 APK。早期测试包的文件名可能带有 `debug`。
4. 在手机上打开 APK，并按系统提示允许浏览器或文件管理器“安装未知应用”。
5. 安装完成后打开 TrailSnap。

请只从 TrailSnap 官方 GitHub 仓库下载；如果 Release 页面提供了 SHA-256 校验值，请在安装前进行核对。
如果 Android 显示 Play Protect 提示，请先确认下载来源和校验值，不要从第三方网盘安装来源不明的包。

## 首次连接服务器

App 首次启动会打开“连接 TrailSnap”页面。请输入**主后端地址**，不需要添加 `/api`：

```text
http://192.168.1.10:8800
```

其中：

- `192.168.1.10` 替换为部署 TrailSnap 的电脑或 NAS 的局域网 IP；
- `8800` 是一键安装脚本默认的后端 API 端口；
- 不要填写 `localhost` 或 `127.0.0.1`，它们在手机上指向手机自身；
- 不要填写 Web 前端的 `8082` 端口；
- 不要在地址末尾添加 `/api`。

点击“测试并保存”。连接成功后，App 会保存该地址并跳转到登录页面。账号、照片和相册数据仍保存在你的 TrailSnap 服务器上。

### 连接前检查

让手机与服务器连接到同一局域网，然后用手机浏览器访问：

```text
http://192.168.1.10:8800/health-check
```

如果无法打开，请检查：

- TrailSnap 的 `server` 容器是否正常运行；
- Docker 是否将后端端口映射为 `8800:8000`；
- 服务器防火墙是否允许手机访问 TCP `8800`；
- Wi-Fi 是否启用了 AP 隔离或访客网络隔离；
- 地址中的 IP 和端口是否正确。

局域网内可以使用 HTTP。通过公网访问时，请配置域名和有效的 HTTPS 证书，避免账号、令牌和照片请求通过明文网络传输。

## 更换服务器

进入：

```text
设置 → 关于 → 更改服务器
```

输入新地址并点击“测试并保存”。切换服务器后，App 会清除当前登录状态，需要使用新服务器上的账号重新登录；服务器端的照片和配置不会因此被删除。

## Android 返回操作

Android 的实体返回键或返回手势遵循以下顺序：

1. 当前有弹窗时关闭弹窗；
2. 当前有上一页时返回上一页；
3. 已在首页或没有可返回页面时，将 App 切换到后台，而不是直接结束 App。

## 更新 App

从 GitHub Releases 下载新版本 APK，并直接安装覆盖旧版本即可。覆盖更新要求：

- 应用 ID 相同；
- 新旧 APK 使用同一发布密钥签名；
- 新版本号高于已安装版本。

正常覆盖安装会保留服务器地址和登录信息。如果系统提示“签名不一致”，不要直接卸载：先确认 APK 是否来自官方 Release。卸载 App 会清除手机端保存的服务器地址和登录令牌，但不会删除服务器上的照片和数据库。

## iPhone 和 iPad

iOS 原生工程已经接入，但公开 IPA 仍需要 Apple 开发者签名。目前推荐使用 PWA：

1. 用 Safari 打开 TrailSnap Web 地址，例如 `http://192.168.1.10:8082`；
2. 点击 Safari 的“分享”按钮；
3. 选择“添加到主屏幕”；
4. 从主屏幕打开 TrailSnap。

这里使用的是 Web 前端端口 `8082`，与 Android App 首次配置时填写的后端端口 `8800` 不同。

## 隐私和安全

- App 连接的是用户指定的服务器，项目维护者不会因为使用 App 而自动获得你的照片或账号数据；
- 服务器运营者仍需自行保护数据库、照片目录、备份和访问凭证；
- 公网访问务必优先使用 HTTPS，并设置强密码；
- 不要把服务器管理端口、数据库端口直接暴露到公网；
- 安装包、服务器和 Web 前端应尽量使用同一版本，以避免接口不兼容。
