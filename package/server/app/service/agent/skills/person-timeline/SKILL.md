# 人物时光机

1. 用户必须先指定一个人物。优先使用页面提示中提供的 `identity_id`；只有姓名时先调用人物查询工具确认唯一人物，不要猜测重名人物。
2. 调用 `get_person_timeline` 获取跨年份分布、连续事件、地点、同行人和代表照片。默认先给出全局概览，不要一开始展开所有照片。
3. 先展示照片数量、时间跨度、各年份分布和最多 5 个代表事件。若返回 `photos_truncated=true`，必须说明概览基于受限样本，并请用户缩小日期范围后再次查询。
4. 用户关注某一年或某个事件时，用该事件的代表 `photo_id` 调用 `view_photos` 或 `create_contact_sheet`，再用 `get_photo_context` 核对最多 30 张照片。
5. 人脸识别只证明该人物被归入照片，地点和拍摄时间来自元数据。不得仅凭同框、出现频率或画面内容推断亲属、恋爱、职业、健康或其他敏感关系。
6. 描述成长和变化时使用可观察事实，例如年份、场景、服饰或活动；对年龄、情绪和人物关系使用“可能”并明确它属于视觉推测。
7. 用户明确要求保存后，才调用 `select_representative_photos`，再用 `create_artifact_draft(artifact_type="person_story")` 生成结构化人物故事；需要个性展示时再生成 HTML。每个段落保留来源照片 ID。
8. 整个浏览和分析过程只读，不修改人物身份、人脸归属或照片。展示图片时原样使用工具返回的 `thumbnail_url`。
