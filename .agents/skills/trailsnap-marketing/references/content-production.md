# 平台文案与视觉制作

## 文案

文风未确定时，同主题先给少量标题方向和一份完整正文。用具体场景开头，亲切但不过度夸张；第一人称只用于有依据的经历或立场。以下是创作建议，不是平台字数限制。

| 平台 | 建议组织 | 交付内容 |
| --- | --- | --- |
| 小红书 | 场景 → 图中展示 → 感受或条件 → 互动 | 标题、正文、话题、封面与逐页内容 |
| 抖音图文 | 首图直给看点 → 每页一个动作或结果 → 末页轻引导 | 标题/配文、话题、按顺序排列的图文成品 |
| 公众号 | 问题与价值 → 场景/教程/更新详解 → 条件与入口 | 标题、摘要、封面、完整 Markdown 正文及插图位置 |

plog 强调照片与经历的叙事，产品截图承担解释作用；教程重视可复现步骤。共用素材也要调整各平台开头、文字密度和结构。话题以相关性为准，不堆砌热词。

## 素材与工具

素材定位起点（相对仓库根目录）：

- Logo：`package/official-site/public/logo.svg`，也可核对 `package/website/src/assets/logo.svg`。
- 历史截图：`doc/image/`；检查版本、界面和公开授权是否适合本次内容。
- 产品主题：`package/website/src/style.css`、`package/website/src/composables/useTheme.ts`；官网视觉查 `package/official-site/`。

Logo 不重画成近似图。真实界面使用目标版本截图，不让图像模型编造功能或界面。浏览器取图时使用可用的 Playwright 技能；访问或登录失败时说明限制，不创建账号或修改公共演示数据。

AI 生成或编辑位图使用可用的 imagegen 技能与工具；没有生成工具时，可用真实素材和排版工具完成海报，或明确缺少的能力。普通海报可用 SVG/HTML 排版，不强制依赖 AI 生图。AI 氛围图须与真实截图区分。

## 图文成品

按叙事确定页数，如封面、问题、操作/功能展示、结果、行动引导，不强制同样长度。为每页确定标题、正文、素材和视觉重点，再制作实际图片。

未指定尺寸时可用 1080×1440 的 3:4 竖版作为工作画布；这是排版起点，不是平台规则保证。发布前核验平台要求与裁切方式，公众号封面另做适配。关键标题和 Logo 留出裁切余量。

默认交付 PNG/JPG；工具支持时保留可编辑源文件。SVG/HTML 不能单独冒充可上传成品；公众号 Markdown 不宣称可原样导入编辑器。

逐张预览导出图片，检查中文缺字、溢出、遮挡、对比度、截图真实性、Logo 清晰度和手机尺寸下的可读性。生成文字须逐字核对，必要时用排版工具覆盖。二维码由已核验链接生成并检查可扫描性，不让图像模型绘制。

多图按 `01-cover`、`02-主题` 等顺序命名。完整包可含文案、图片、源文件和内部制作备注（来源、授权状态、待核验项）；只创建本次需要的文件。交付时展示关键图片并链接其余成品，明确未完成的渲染或素材缺口。
