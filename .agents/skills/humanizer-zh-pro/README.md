# 中文降 AI（humanizer-zh）

去除中文文本中的 AI 生成痕迹，使其更自然、有人味。适用于编辑或审阅**公文、工作月报、学术论文、宣传稿、汇报材料**等中文文本，去除"AI 腔 / 机器腔"。

> 技能标识：`humanizer-zh`（中文显示名：中文降 AI）。基于维基百科 "AI 写作特征"（WikiProject AI Cleanup）指南翻译扩充，并针对中文政务 / 学术文稿补充专项规则。

---

## 适用场景

- 论文 / 汇报 / 月报 / 公文去 AI 味，降低 AIGC 检测率
- 审阅 AI 代写稿，识别并改写典型 AI 痕迹
- 在保留全部事实、数据、结论的前提下提升文本"人味"

## 使用方法

直接告诉本技能要处理的文本与目标检测器（投稿 / 送审通常采用**知网**或**万方**官方检测；若机构采用激进档如朱雀 / BestPaper，以其报告为准）。

```
请对下面这段文字去 AI 味（目标检测器：万方）：
……
```

或仅做检测：

```
只检测下面这篇稿子的 AI 率，按检测器分档给结论，不改写：
……
```

## 核心结论（必读）

**AIGC 检测工具的结论不可混用、不可相互印证。** 同一篇文本，不同检测器给出的 AI 率可能相差数倍，且标注片段几乎不重叠。务必以**目标机构同款检测器、同一口径**复测为准。

检测器敏感度光谱（2026 实测校准）：

| 档位 | 检测器 | 特征 |
|---|---|---|
| 激进档 | 朱雀 / BestPaper / 论文狗 | 正文口径常见 71–83%，敏感"密集空泛 + 结构对称"的句式密度 |
| 中等档（模板凶） | 万方 | 对模板化 / 定义类 / 算法描述 / 摘要八股最敏感，同篇可 56% vs 知网 21% |
| 中严档（规整凶） | 知网 | 对写作逻辑高度规整的人类原创综述 / 推导 / 定义更敏感，3.0 持续升级 |
| 中等档（句式凶） | 维普 | 对均匀长句 / 连接词密集 / 段落对称最敏感，波动极大（同篇可 67% vs 知网 3%） |

**真正敏感的是"空泛 + 整齐"的句式密度，不是数据本身。** 同一数据被空泛对称包裹时仍会被标红；拆开包裹（破对称、补主语、口语化展开）后即便保留数据也可大幅下降。

## 注意事项

1. 质量评分以 AIGC 检测工具给出的"AI 率 %"为准（越低越好），不采用主观 /50 制；须用目标机构同款检测器复测。
2. 参考文献按学术规范正常排版即可，不要为降 AI 率改写 / 打乱 / 删减参考文献格式——部分激进档会误标参考文献，但知网 / 万方通常不计入 AI 率。
3. 优先按目标机构检测报告的**标注片段**改写，避免凭"感觉像 AI"大改未标注段落，损伤信息量。
4. **强制流程（2026-09-18 修订）**：每次去 AI 操作**前**，须先预估文档在知网 / 万方 / 维普三平台的 AI 率并告知用户（基于校准档案的特征预估，非送检实测）；修订**完成后**须附质量评分表，含三平台修订前 / 后预计 AI 率对照（详见 SKILL.md 第四节步骤 0 与第六节）。
