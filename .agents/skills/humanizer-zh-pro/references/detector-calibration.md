# 检测器校准证据汇总（脱敏）

> 本文件汇总 `humanizer-zh` 技能所依据的检测器敏感度校准证据。**所有样本均已脱敏**：不出现任何作者姓名、单位名称、论文名称、具体来源署名，仅保留可复现的检测数值与结构结论，用于支撑 SKILL.md 中的规则 X（知网）/ Y（万方）/ Z（维普）及通用规则 U（敏感度光谱）/ V（参考文献假阳性）/ W（统计分组对称）。

---

## 一、检测器层级模型（核心结论）

同一篇文本在不同检测器下 AI 率可相差数倍，且标注片段几乎不重叠。实测校准后的层级：

| 档位 | 检测器 | 敏感维度 | 典型正文 AI 率区间 |
|---|---|---|---|
| 激进档 | 朱雀 / BestPaper / 论文狗 | "密集空泛 + 结构对称"的句式密度 | 71–83%（同稿三档互证） |
| 中等档（模板凶） | 万方 | 模板化 / 定义类 / 算法描述 / 摘要八股 / 标准化学术用语 | AI 辅助稿 45–69%；重度模板可达 85% |
| 中严档（规整凶） | 知网 | 写作逻辑高度规整的人类原创综述 / 推导 / 定义 | 纯 AI 37–78%；AI 辅助 21–45%；手写规整 29–47%；纯人工 2–3% |
| 中等档（句式凶） | 维普 | 均匀长句 / 连接词密集 / 段落对称 / 整齐排比 | 纯 AI 75–95%；AI 辅助 47–72%；波动极大 |

**关键反证（跨平台同篇对照）**：同一篇论文，知网 3% vs 维普 67%（维普高 64 点）；同一篇算法定义密集硕论，万方 56% vs 知网 21%（万方高 35 点）。三者敏感维度各异，**数值不可互通预估**，改写须按目标机构那款检测器的标注片段优先处理。

## 二、激进档互证（同一统计型稿件，三档对照）

某统计型稿件（约 8000 字，31.7% 句子带具体数字 / 年份）：

| 检测器 | AI 率 | 标注特征 |
|---|---|---|
| BestPaper | 78.15%（42 段 High） | 统计分组对称段（优 / 高 / 中 / 低四并列 + %、①②③ 枚举、三对称） |
| 腾讯朱雀 | 82.51% 疑似（其中 20.96% 为 AI 特征） | 片段 2（统计分组对称）0.9966 vs 片段 4（数据密集但叙述化）0.2560 |
| 论文狗 | 全文 47.63% / 正文 71.08% | 逐段峰值：案例剖析 100%×3、治理响应 100%、空间分异 81.09%、关键制约 76.89% |

**结论**：每个 80%+ / 100% 高分段都精确对应一个"统计分组对称"结构；数据密集但叙述化的段落反而降级。触发的是**结构对称**，不是数据本身（规则 W）。

## 三、知网（中严档）校准证据

基于 5 份公开检测报告（均已脱敏，来源泛化为"公开报道样本 / 第三方实测样本 / 高校自查样本"）：

| 样本类型 | 知网 AI 率 | 关键对照 |
|---|---|---|
| 记者纯 AI 长文（公开报道样本） | 37% | 同篇维普 46%、PaperPass 69%（知网最低） |
| 同一作者两篇，无改动复测（公开报道样本） | 71.2% → 18.4%（波动 52.8%） | 半小时内复测波动极大 |
| 某受访者稿（公开报道样本） | 45.1% | 同篇 PaperPass 97.9%（相差 52.8 点） |
| 算法定义密集硕论（第三方实测样本） | 21%（合规） | 同篇万方 56%（高风险）——证伪"万方 = 温和档" |
| 高校硕士讨论部分（自查样本） | 42% → 8% | 官方标黄阈值 = 连续 13 字符 |
| 财务管理本科稿（实测样本） | 41.6% → 5.1% | 标红集中在"理论基础 / 指标分析"章；数据表未标红 |
| 手写零 AI 误判实测（实测样本） | 整体 29% | 文献综述 41% / 推导 47% / 定义 35% / 案例仅 8%（误判与内容类型强相关） |

**知网要点**：标称准确率 98.6%、严格度"较严"；误判重灾区 = 文献综述 / 理论定义 / 公式推导 / 实验步骤 / 教科书式描述；易标红词 = 首先 / 其次 / 再次、一方面 / 另一方面、综上所述 / 由此可见、段落均匀 150–200 字；标红机制 = 连续 13 字符标黄、置信度 80+ 确认 / 50–80 疑似 / <50 原创；2026 通用阈值：本 ≤30% / 硕 ≤20% / 博 ≤10% / 刊 ≤25%。（规则 X）

基于 5 份公开检测报告（脱敏）：

|---|---|---|
| 深度学习硕论（实测样本） | 69.7% → 7.2% | 标红集中"模型结构阐述 / 相关工作"；伪代码 / 公式 / 表格未标红 |
| 综合稿 8200 字（实测样本） | 45.3% → 5.1% | 文献综述 67.8→6.3 / 模型 38.2→4.8 / 结论 51.6→7.2 |
| 管理学硕论（实测样本） | 63.4% → 5.8%（同篇知网 6.4%） | 多组：教育学 45→5、公管本科 50→7.5、文学 58→6.5 |

## 五、维普（中等档·句式凶）校准证据

基于 5 份公开检测报告 + 1 份关键跨平台反证（脱敏）：

| 样本类型 | 维普 AI 率 | 关键对照 |
|---|---|---|
| 新传硕 DeepSeek 辅助稿（实测样本） | 55.2% → 8.4% | 标红集中 20–30 字均匀长句；长短交替后降分 |
| 某章节约 560 字（实测样本） | 87% → 12%（全文 41%→12%） | 标红 = 句式统一工整、长句均匀 |
| 某稿 3500 字（实测样本） | 68.2% → 11.7% | 误差 2.1% |
| 某稿 5000 字（实测样本） | 72.3% → 8.7% | 误差 2.1% |
| 市场营销本科 DeepSeek 稿（实测样本） | 92.3%（各章 88–97%）→ 3.2% | 纯 AI 稿维普普遍 75–95%；学校 ≤30% |
| **跨平台反证** | **知网 3% vs 维普 67%**（维普高 64 点） | 维普按句式工整度拆段，纯手写致谢 / 英文摘要被误标 |

**维普要点**：按 150–200 字拆段扫描"句式工整度 + 连接词密度"，对均匀长句 / 连接词密集 / 段落对称最敏感，波动极大；纯 AI 稿 75–95%、AI 辅助 47–72%；标红机制 = 绿 <20% / 黄 20–50% / 红 >50%，句子级标注；2026 阈值：本 ≤30% / 硕 15–20% / 博 ≤10% / 刊（社科）≤20%。（规则 Z）

## 六、参考文献假阳性（规则 V）

- BestPaper 等激进档会把参考文献（短、格式统一、缺乏语义变化）误标为 88–98% 高疑似；同一文档"彻底降 AI 版"唯一残留 High 即一条参考文献引文（91.06%）。
- 但**并非所有检测器共有**：朱雀将参考文献段判为 0.0001（未误标）；论文狗对参考文献 / 作者简介 / 关键词无任何高疑似标注；知网 / 万方通常不计入 AI 率。
- **操作**：参考文献按学术规范正常排版即可，不要为降 AI 率改写或删减格式。

## 七、对去 AI 改写规则的启示（可直接落地）

1. **中等档（万方 / 维普）送审**：重点清理摘要八股（Q）、拔高尾巴（R）、"并…并…"排比（S）、模板化 / 定义类（Y）、均匀长句与整齐排比（Z）；带具体事实的排比 / 年表 / 数据表一般不触发，保留。
2. **中严档（知网）送审**：除 Q–T 外，额外清理文献综述 / 理论定义 / 公式推导 / 实验步骤等"太规范"章节的密集堆叠（X）；统计分组对称（W）与数据段一般不触发，不必强行重写。
3. **激进档（朱雀 / BestPaper / 论文狗）**：必须把 J/L/M/N/O/W 的句式架构改写成"有主语、长短交错、以具体事例 / 数据落脚"——目标是降空泛、破对称、拆包裹，不是删数据。
4. **保数据、拆包裹二者并行不悖**："有数据就安全"是误区；先拆包裹（破对称、补主语、口语化展开），数据一字不删。
