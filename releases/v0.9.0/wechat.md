# 行影集 v0.9.0 发布：朋友圈日记、位置拼图与移动端体验升级

行影集 v0.9.0 正式发布。本次更新围绕“重新看见照片”展开：按天浏览时可以得到一段自然的朋友圈文字，按地点浏览时则可以把旅途照片拼成一张可探索的地图。同时，移动端导航和地图操作也进行了重新整理。

## 朋友圈日记：从照片到一段自然的文字

v0.9.0 为朋友圈布局增加了按天生成文案的能力。系统会结合当天照片中的地点、人物、事件和氛围，生成一段适合继续修改或直接发布的文字，生成过程会实时呈现；用户可以编辑、清除并重新生成。

每天的内容还会展示主要地点与照片高光。短途旅行结束后，打开对应日期即可看到地点概览、精选照片和一段可以继续调整的文字，不必重新翻阅整个月的相册。系统设置支持自定义文案提示词，并选择关闭、按间隔或每周定时生成，让照片回顾更容易成为日常习惯。

## 位置相册拼图：把走过的地方拼起来

位置相册新增照片拼图视图，照片会沿着省级地图轮廓排列，支持先浏览全国、再进入具体省份查看细节。用户可以按回忆价值、画质、最新拍摄或随机方式选片，也可以切换手动策略，直接点击格子替换、移除照片，并用省份过滤缩小选择范围。

拼图照片池会自动减少相似的连续拍摄画面，让最终组合更丰富。地图区块支持双击下钻，省份视图增加面包屑导航；精细度调整和“换一批照片”也让同一段旅程可以呈现出不同组合。

## 移动端：常用入口更近，操作更自然

移动端导航改为底部 Tab 栏，其他入口集中到“更多”抽屉，单手操作更方便。地图和拼图的信息面板改为可收起、展开的底部面板，并支持缩放和拖拽；AI Agent 侧边栏也改为带遮罩的抽屉模式，打开后可以明确关闭，不再遮挡页面头部。

用户昵称和头像信息现在会持久化保存，刷新页面或直接打开深层页面时不再短暂显示默认昵称。

## 部署与体验优化

本版本优化了 Server 与 AI 服务镜像构建，减少部署体积和启动开销；AI 服务增加优雅停止与健康监控，升级或重启时更平稳。

同时修复了朋友圈本地时区聚合、流式文案显示、单图比例、移动端真机拼图空白、位置编辑省市区解析、最近去过层级跳转、人物相册空壳身份排序、图库选择器滚动空白，以及外部图库校验和任务跳转等问题。

## 如何升级

**Docker Compose 部署**

```bash
git pull
docker compose pull
docker compose up -d
```

**源码部署**

```bash
git pull
cd package/server && uv sync
cd ../ai && uv sync --extra cpu
cd ../website && pnpm install && pnpm build
```

本版本包含朋友圈日文案相关数据库迁移，使用项目启动脚本或 Docker Compose 启动时会自动执行。升级前仍建议备份数据库。

完整更新内容可查看 [GitHub Release v0.9.0](https://github.com/LC044/TrailSnap/releases/tag/v0.9.0)。
