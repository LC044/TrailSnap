## 新功能

### 文件夹浏览

- 新增按扫描目录层级浏览照片，支持面包屑导航，在保留原始文件夹结构的同时快速定位内容。
- 文件夹视图支持网格与列表两种模式，可按名称、时间和大小排序，并可直接进行选择、下载、加入相册、加入人物和删除等操作。
- AI Agent 获得文件夹上下文，可查询文件夹结构及指定目录中的照片。

### CLI 与自动化

- TrailSnap CLI 新增 `tasks` 命令，支持查询、创建、等待、取消、重试、暂停和恢复后台任务。
- 新增 `toolbox` 命令，可通过命令行使用重复照片、相似照片、清理建议、照片整理、批量重命名和文件名时间提取等工具。
- 新增 JSON 格式错误输出，并完善 CLI 单元测试、集成测试与统一测试入口。

### 部署与账户安全

- 新增演示模式。通过 `DEMO_MODE=true` 启用后，可统一限制写操作并自动隐藏 API 密钥、存储路径等敏感配置，便于安全地开放在线体验。
- 忘记密码时新增“服务器验证码”兜底方式。验证码仅写入服务器日志，具备有效期、重发间隔、失败次数限制和用后失效机制。

## 体验优化

- 首页和照片页启用页面缓存，返回页面时保留浏览状态，并在重新激活时刷新数据。
- 优化“断舍离”的滑动与删除体验：网络中断时暂存删除操作，恢复连接后自动同步，并修复卡片闪现问题。
- 统一主要 API 的成功响应格式为 `{code, msg, data}`，CLI 和前端已同步适配。
- 优化文件夹照片统计与查询，避免逐目录查询，在大型照片库中浏览更顺畅。

## 修复

- 修复 `uploads` 目录照片数量显示为 0 的问题。
- 修复照片颜色数据外键异常导致相关任务停留在处理中并反复执行的问题。
- 修复文件夹视图出现冗余工具栏的问题，将布局切换入口统一收纳到文件夹工具栏。
- 修复演示模式拦截写操作时前端无法正确读取提示的问题。

## 升级提示

- 本版本未包含数据库结构迁移。
- 自行开发的 API 客户端需要注意：部分接口响应已统一为 `{code: 0, msg: "success", data: ...}`，业务数据应从 `data` 字段读取。官方前端和 TrailSnap CLI 已完成适配。
