# 行影集 v0.8.0 更新｜终于能按文件夹逛照片了📁

行影集 v0.8.0 来啦！这次把很多人一直惦记的文件夹浏览补上了，也让照片整理和日常使用更顺手。

【按原文件夹浏览】
不需要改变硬盘里原有的整理习惯，现在可以沿着文件夹一层层进入，网格和列表两种视图随时切换，还能按名称、时间、大小排序。旅行、家庭、工作素材各放各的，找照片终于不用全靠搜索。

【断舍离更安心】
清理照片时遇到网络波动，删除操作会先记下来，恢复连接后再自动同步；滑动时偶尔闪出上一张卡片的问题也修好了，连续筛选更流畅。

【回来还是刚才的位置】
首页和照片页现在会保留浏览状态。看完详情再返回，不必每次都从头翻；页面重新打开时也会自动刷新最新内容。

【忘记密码多一条退路】
除了安全问题，现在还可以通过服务器日志中的验证码重置密码。对自托管用户来说，关键时刻多了一种可靠的找回方式。
