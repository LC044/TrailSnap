# 扫描后基本处理性能优化与对比（2026-10-10）

基线版本：`d8abce23f4f4e8cec6794c49454901f30925322d`，优化后为当前工作区。

## 测试方法

- Windows；28 个逻辑 CPU、约 64 GiB 内存；Python 3.12.2、SQLite 3.43.1、Pillow 12.3.0、OpenCV 4.12.0。
- 从同一原始目录按文件大小分位选取 24 个文件：12 JPEG、6 PNG、6 MP4。两个版本的文件路径、大小、修改时间清单哈希一致。
- 固定 4 个线程、每批 8 个文件，各运行 3 轮。原图只读；所有预览和数据库使用自动清理的临时目录。
- 每轮新建独立 SQLite WAL 数据库，计时范围为 BasicTaskStrategy 的处理/入库/下游任务生成，以及 ExtractMetadataStrategy 的元数据处理。
- 第一轮包含离线地理编码冷初始化，后两轮复用进程中的地理编码数据；不包含 AI 分析、真实任务队列调度、文件夹扫描、任务状态更新/清理，也不代表整个 1,861 文件图库的端到端耗时。
- SQL/事务计数排除建表、测试账号建立和结果验证；数据库与预览图不写入真实图库。

相同文件集的两阶段吞吐约提高 **2.32 倍**。首次冷启动总耗时从 9.783s 到 8.332s；冷初始化本身仍有成本，后台执行减少了调度线程阻塞。

MD5 保存数量从 0/24 到 24/24。两个版本的性能原始数据：[优化前](basic-performance-before.json)、[优化后](basic-performance-after.json)。三轮耗时有波动，应结合原始数据阅读，不能将单轮最优值外推到全图库。

## 实现范围

1. WebP 默认使用 method=0，质量参数和目标分辨率保留；可通过 image.webp_method（0～6）调整编码努力程度。
2. EXIF 方向校正后先缩小工作图，从工作图生成两种尺寸，减少全分辨率复制和内存占用。
3. 视频封面按现有亮度/空白帧检查寻找可用帧，找到后提前结束；评分只使用下采样像素。它不再遍历所有候选帧寻找最高得分，封面选择可能变化。
4. 基本处理按用户批量查询已有路径、已有照片/元数据与颜色信息，批内缓存图像/过滤配置和存储根目录。
5. 基本处理保存已经计算的 MD5；哈希默认读取块由 8 KiB 改为 1 MiB。
6. 元数据批次在后台线程内建立并关闭独立会话；批量预取照片、元数据和场景，一次提交，按用户合并条件/智能相册更新。离线地理编码初始化和访问加锁。
7. 完成结果的写入转入后台线程，结果循环仍顺序等待每次写入；系统状态保存避免阻塞调度线程。
8. CPU 消费并发上限对齐实际线程池（低/中/高为最多 4/8/16）；历史自适应限流数据超过 60 秒不再用于启动。基本处理批次从 16 改为 4，减少整批等待。
9. 线程池生命周期同时考虑 CPU/IO 活动，防止 CPU 基本处理仍运行时被当成 IO 空闲池关闭。

数据库 ORM 模型未改变，不新增迁移；已有路径索引的状态已核对，未凭小数据快照新增索引。

## 质量与体积

18 张图片按方向校正、缩放后的原图作为参考，解码 WebP 后计算 PSNR（越高越好）：

| 指标 | 优化前 | 优化后 |
|---|---:|---:|
| 预览平均 PSNR | 40.23 dB | 40.34 dB |
| 小缩略图平均 PSNR | 36.32 dB | 36.21 dB |

24 个媒体文件生成的预览图和小缩略图合计从 3.94 MiB 到 4.90 MiB，增加 24.4%。快速编码的空间代价需要计入；PSNR 是样本指标，不能保证所有图片感知质量相同。原始数据：[质量结果](basic-thumbnail-quality.json)。

## 复现

在对应版本的 `package/server` 下运行（基线测量需要基线代码及相同的基准脚本）：

```powershell
.\.venv\Scripts\python.exe scripts/benchmark_basic_pipeline.py --root <媒体目录> --output <结果.json> --rounds 3
.\.venv\Scripts\python.exe scripts/benchmark_thumbnail_quality.py --root <媒体目录> --baseline-ref d8abce23f4f4e8cec6794c49454901f30925322d --output <质量结果.json>
```

脚本使用临时数据库，不读取真实账号，不触发 AI 请求，不修改原图。
