# PR #331 首次迁移体验与统一文件夹展示验收

关联需求：[REQ-167](https://feedback.trailsnap.cn/REQ-167)。以 `6950e58bcbc39da17aa902392237c4f3afdd17a5` 开始，在独立工作树实现及验证，并快进接入分支新增提交 `a5b1ccfed5b5cdb2075d51835c390e88a5a48243`；未操作真实图库。

## 行为

- Windows 启动器在后端和网页启动前创建原生窗口，展示检查、原照片基准、复制与校验、数据库升级、切换、候选验证和正式启动等阶段。已知总量显示实际处理量，复制阶段包括复制与两次内容校验；未知总量显示活动进度和耗时，不伪造百分比。
- 三个根目录入口共享按规范化安装路径区分的协调器，重复启动唤回迁移窗口或正常客户端；不同安装目录独立运行。同一数据目录仍由既有锁保护。
- 可中断阶段的“稍后继续”在文件安全点停止，保留旧数据。请求只对当前启动有效；未完成的复制重新进行。数据库与发布阶段不强杀写入；关闭原生窗口在可中断阶段请求暂停，在关键阶段仅最小化。
- 暂停和失败可原地重试、查看日志或退出。维护目录不可写也保持同一个错误窗口。只读临时副本可清理，不修改源文件权限。正常客户端在就绪前主动退出时不另弹失败窗口，也不清理旧数据。
- 设置 → 照片与数据位置仅展示实际行影集根目录，并通过同一个根目录入口打开文件夹。默认路径随实际用户名和安装位置变化，不写死；不展示内部数据子目录。搬迁说明要求安全退出、整体移动、从新位置打开并更新快捷方式。外部原照片依赖提示保留；高级分离资料位置时额外说明不会随程序一起搬走。

设置浏览器检查使用 Playwright CLI、真实 Vue 组件和 Pinia，原生接口使用隔离替身：1280px 浅色、390px 深色与不同强调色；展开搬迁说明，确认唯一根目录、无内部数据路径、无横向溢出，点击打开文件夹调用实例根目录命令。此项不冒充实际资源管理器跳转或真实账号登录。

Windows NSIS、冻结后端、启动器及 WebView2 原有自动迁移回归 **3 passed / 9 deselected**：正常迁移清理、原图 SHA-256、旧登录令牌、候选损坏后恢复、同版本修复及中文安装位置识别。最终可见窗口实包专项 **1 passed / 11 deselected**：界面响应、三个入口复用、暂停后源数据库哈希不变且没有发布实例、原地重试完成同一操作、正式就绪后删除旧受管理数据、从最小化状态唤回正常主窗口。最终程序构建为 `0.17.4-5f8c24a04411de4d`；窗口专项使用重新打包的最终启动器，前述三项在进度共享冲突修复前验证，修复后另通过专项单元与完整可见窗口流程。

验收中修复进度文件的 Windows 共享冲突：读者或扫描器短暂拒绝原子替换时，进度上报跳过本次写入、后续重试，不使数据事务失败；暂停检查仍有效。测试夹具将安装器路径规范为 Windows 路径，避免 NSIS 将可执行路径中的 `/release` 误读为 `/R`，并在查找窗口前按进程筛选、保留实际退出原因。安装器验收串行执行。

实包测试还检查正式客户端最小化后的重复启动：同进程的 WebView 辅助窗口不能冒充主窗口。唤回时过滤无标题和工具窗口；夹具按实际主窗口标题定位，避免枚举顺序改变后验证了错误窗口。最终启动器再通过完整桌面回归，并用相同生成的 NSIS 脚本重新打包验证。
