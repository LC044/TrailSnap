## 实现行为

- Windows 启动器在首次创建空库之前发现历史默认目录、覆盖安装目录与历史自定义指针。唯一可确认的旧库自动复制到当前安装的 `userdata`，无需另选完整实例目录；无旧库时正常初始化。
- 复制逐文件校验，自动迁移对全部原先可读照片保存并核对完整 SHA-256。最终位置候选启动验证通过、正式客户端服务就绪后才提交旧数据清理。
- 清理仅针对已复制、源哈希仍匹配的受管理文件。外部原照片、未知附属文件和旧浏览器缓存保留。保留认证密钥和可用的历史连接端口；旧登录令牌可继续使用。
- 多来源、不可用来源、非空目标、写入占用、复制或验证失败时保留原库，不建立替代空库。异常来源可通过启动器原生对话框确认，取消不修改旧数据。已有实例继续使用原配置，不自动覆盖已建立的新图库。
- 持久记录复制、发布、验证和清理阶段；复制失败可重做自有暂存副本，发布中断可恢复配置，候选损坏可修复安装后重新验证，清理中断按已提交记录继续。
- 安装器默认选中唯一已有安装，显式 `/D` 保持有效；多安装静默升级要求指定 `/D`。中文路径通过 UTF-16 文件交给 NSIS，避免控制台编码损坏。
- 同版本重装核对实际程序内容并替换损坏、缺失或多余资源，保留实例与用户数据；拒绝修复包含图库或链接的程序目录。
- 稳定启动器嵌入现有行影集 ICO，因此安装根目录的三个入口均有图标。冻结后端补入铁路初始化 CSV。

## 边界

本轮为 Windows x64 合成历史图库验收，未运行用户真实旧库或真实旧版本安装包；未人工逐页操作向导和原生目录选择器，未进行真实断电、macOS/Linux 安装或正式签名发布验收。中断用例通过构造明确的持久阶段验证恢复。外部原照片仍依赖其原目录；未知文件和缓存可能保留。多来源、已有新图库等冲突状态需要确认，不能静默覆盖。

本地验收包关闭更新附件签名并使用 zlib 压缩，不代表正式发布或新的远端 CI 已通过。提交后的远端 CI 结果以 PR 当前提交的检查状态为准；本记录描述本地验收结果。
