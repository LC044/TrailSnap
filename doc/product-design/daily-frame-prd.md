# 一日一帧：产品需求文档

版本：v1.0 草案

日期：2026-10-03

产品：TrailSnap（行影集）
状态：待评审；本次交付为需求设计，尚未实现功能。

## 1. 产品定义

**每天留下一个代表瞬间，把一段时间的生活拼成一部短片。**

“一帧”是一个日期对应的代表素材：普通照片展示一秒，视频或 Live Photo 截取一秒。用户通过日历选择和替换素材，按月、年或自选日期范围生成影片。

核心体验是“选一个 → 看积累 → 播放成片”。使用已有图库即可开始，不要求每天拍摄、不要求每天打开应用；允许补选过去的日期。空缺日期自然保留在日历中，成片默认跳过，不用连续打卡惩罚用户。

参考：1 Second Everyday 的每日短片段与日期范围合成方式，见 [官网](https://1se.co/) 与 [官方合成说明](https://help.1se.co/en/articles/3703781-how-to-choose-the-dates-to-mash)。本方案是适配行影集的独立设计。

## 2. 目标与典型场景

| 场景 | 用户行为 | 得到的结果 |
| --- | --- | --- |
| 日常记录 | 晚上从当天照片里挑一个瞬间 | 每月形成生活短片 |
| 回顾旧相册 | 打开过去的月份，批量填充后逐日调整 | 不需要重新拍摄就能开始 |
| 旅行回顾 | 选择旅行日期，每天留一个片段 | 七天旅行得到约七秒的影片 |
| 阶段记录 | 持续挑选成长、校园、家庭生活的代表瞬间 | 一年内的变化以紧凑影片呈现 |

产品目标：降低挑选与制作门槛；让已有照片获得持续回顾的机会；形成可下载的明确成果。

## 3. 首版范围与后续扩展

### 3.1 首版必须完成

- 每个用户一个独立的一日一帧日历，每个日期最多一个选帧。
- 月历与年度总览，手动选帧、替换、修改一句话、移除选帧。
- 支持照片、视频、带可用动态文件的 Live Photo。
- 视频及 Live Photo 选择一秒片段；不足一秒的处理见第 7 节。
- 当月批量填充，用户确认候选后保存。
- 按月、年、自选日期生成预览和下载 MP4。
- 导出进度、历史作品、失败重试与素材失效处理。
- 桌面与移动端适配、暗色主题与基础无障碍操作。

### 3.2 后续扩展

- 多个独立项目，例如“孩子成长”“我的通勤”；项目内每天一个片段。
- 每日提醒、桌面小组件、直接拍摄和系统分享入口。
- 音乐、原声、转场、片段时长调整和更多影片模板。
- 从记忆或人生章节一键建立独立项目、多人共同记录。
- AI 解释候选、按用户偏好推荐、跨日主题连续性推荐。

首版影片固定每个有效日期一秒，静音，使用直接切换。普通照片不加入动画，先保证预览与导出一致。此范围不依赖大模型配置。

## 4. 入口与页面结构

### 4.1 入口

| 位置 | 展示与行为 |
| --- | --- |
| 记忆页面顶部 | 桌面与移动端均展示“一日一帧”按钮，点击进入主页面；侧栏及移动端“更多”不单独列出此功能 |
| 首页 | 简洁卡片：今天未选时显示“为今天留一个瞬间”；已选时显示今日缩略图和“查看本月” |
| 照片查看器操作菜单 | “设为当天一帧”；打开选帧编辑器，日期依据拍摄时间；已有选帧时展示替换前后对比 |

照片缺少真实拍摄日期时，查看器入口置为不可用，并提示“补充拍摄日期后，才能设为当天一帧”。不使用上传日期代替拍摄日期。

### 4.2 页面与返回行为

- 主页面：月历、年度总览、作品列表；默认当前月份。
- 选帧编辑器：桌面侧面板；移动端全屏页面。
- 批量填充：桌面弹窗；移动端全屏页面。
- 影片制作页：日期范围、画面设置、预览、生成与下载。
- 作品详情：影片播放器、范围、生成时间、下载及删除。

建议路由：`/daily-frame`、`/daily-frame/create`、`/daily-frame/works/:id`。主页面保留月份、视图和滚动位置；关闭编辑器返回原日期，不跳回当前月份。

## 5. 主页面展示

### 5.1 桌面布局

```text
一日一帧                         [我的作品] [制作影片]
每天留下一个代表瞬间

[月历 / 年度]   < 2026 年 10 月 >   [回到本月] [填充本月]
本月已留下 3 个瞬间 · 截至今天还有 0 天待选

周一   周二   周三   周四   周五   周六   周日
                     [1图]  [2图]  [3图]  [4未来]
……

选中日期时打开侧面板：
10 月 3 日 · [代表片段预览] · 一句话 · [更换] [移除]
```

- 月历占主要空间，七列布局，日期单元接近正方形。
- 缩略图使用填满裁切；成片是否裁切由影片设置单独决定。
- 日期、动态素材标识置于对比足够的底色上，不能只依靠图片亮度。
- 首次进入展示简短说明和“从今天开始”“挑选过去的月份”，不自动生成作品。
- 今天无照片时说明“今天还没有可选素材，导入照片后再来”，保留跳转图库入口。

### 5.2 日期单元状态

| 状态 | 展示 | 点击行为 |
| --- | --- | --- |
| 已选照片 | 缩略图、日期；有一句话时显示小标识 | 打开编辑器，展示当前选帧 |
| 已选动态素材 | 缩略图、日期、播放标识 | 打开编辑器；不在整个月历中自动播放 |
| 有素材、未选 | 中性底色、日期、“选一帧”；桌面悬停显示候选数 | 打开当天候选 |
| 无素材、未选 | 淡色底、日期、“无素材” | 打开空状态和导入入口 |
| 素材失效 | 保留日期，显示警示图标和“需更换” | 展示失效原因和可用候选 |
| 未来日期 | 低强调日期，不显示选择按钮 | 不可选择，说明“这一天还没到” |
| 非当前月日期 | 空白占位，不混入前后月素材 | 不响应选帧 |

今天增加主题色描边；选中日期增加独立焦点标识。照片失效不计入“有效瞬间”数量。未来日期不计入待选数量。

### 5.3 移动端

- 顶部保留标题和“制作影片”；年份、月份可点选，不要求连续滑动翻多个月。
- 月历保持七列。小屏日期单元只放日期、缩略图和类型标识，不塞入文案。
- 单元整体可点击，高度满足触控需求；候选数、失效原因进入编辑器查看。
- 点击日期进入全屏编辑器，底部固定保存按钮；关闭或系统返回时处理未保存修改。
- 支持横向手势切换月份，同时保留前后月按钮，避免手势成为唯一入口。

### 5.4 年度总览

- 显示十二个月的小型缩略日历，已选日期呈现代表图，空缺日期保留中性底色。
- 桌面四列月份卡片，移动端两列，月份卡点击后进入该月月历。
- 顶部显示“今年留下了 N 个瞬间”；不设置连续天数排名、红色缺勤提示。
- “制作这一年”快捷入口自动带入当年范围；当前年份截止今天。

## 6. 手动选帧与编辑

### 6.1 打开某一天

1. 显示日期、候选总数和当前选帧（如有）。
2. 候选仅来自当前用户可访问、未删除且真实拍摄日期属于该日的素材。
3. 默认按拍摄时间升序，支持“照片 / 动态素材”筛选；Live Photo 作为一个素材呈现，不把配套视频再显示一次。
4. 缩略图展示拍摄时间、视频时长或 Live 标识，已选候选有明确标记。
5. 点击候选进入预览和编辑区。编辑前不会修改已保存选帧。

候选按页加载，不一次请求整日全部原图。预览区使用完整画面；动态素材只有用户点击播放后才播放。

### 6.2 选普通照片

- 完整预览，底部提示“这张照片将在影片中展示 1 秒”。
- 输入可选的一句话，最多 30 个字符，显示计数。例如“晚风刚刚好”。
- 点击“保存这一帧”后，日历立即显示结果，并提示“已留下今天的瞬间”或“已保存 10 月 2 日的一帧”。
- 保存过程中禁止重复提交；保存失败保留编辑内容，提供重试。

### 6.3 替换与移除

- 更换素材保留已有一句话，用户可修改；动态片段起点不继承到新素材。
- 取消编辑保留原选帧。未保存的素材、起点或文字发生变化时，返回提示“继续编辑 / 放弃修改”。
- 移除前说明“只移除这一日的选帧，原照片仍在图库中”。确认后日期回到待选状态。
- 移除操作成功后提供一次撤销；撤销若遇到该日已有新选帧，提示冲突，不覆盖新内容。
- 查看器快捷设置遇到当日已有素材时，展示旧图和新图，按钮为“替换当天一帧”，不能静默覆盖。

## 7. 动态素材的一秒编辑

```text
10 月 3 日 · 选择这一秒
[视频预览；完整构图]

00:00 ── [选中区间 00:02.0—00:03.0] ── 00:08
起点 00:02.0                         [播放这一秒]
一句话：__________________________
                             [保存这一帧]
```

- 选中区间固定一秒，拖动整个区间选择起点，不拖动端点改变长度。
- 起点默认 0 秒；允许以 0.1 秒步进微调，键盘和按钮均可操作。
- 起点范围为 `0` 至 `素材时长 - 1 秒`，不可越界；只预览选中区间，用户可主动循环播放。
- 首版选帧预览和导出均静音，播放器明确显示“静音片段”。
- 素材不足一秒且能够解码时，播放到末尾后保持最后一帧，补足一秒，并显示说明。
- Live Photo 缺少动态文件时，可用其静态照片，界面提示“动态片段不可用，将使用照片”。用户确认后按照片保存。
- 视频无法播放时，先显示加载失败和重试；不悄悄用缩略图代替动态素材保存。
- 用户点“使用静态画面”时，Live Photo 可切换为其原始照片；普通视频首版不提供截图选帧。

## 8. 当月批量填充

按钮文案为“填充本月”，副说明为“为还没选的日子挑选候选，你可以逐个调整”。

1. 只处理该月截至今天、有可用素材但没有选帧的日期。失效选帧保留为需修复状态，不算未选日期。
2. 生成候选清单，每个日期一张预览，显示类型；动态素材初始截取起点为 0 秒。
3. 首版采用确定性选择规则：优先可读取的普通照片，其次可读取的 Live Photo，再其次视频；同类型优先已有有效质量评分较高者，评分缺失或相同时按拍摄时间、素材 ID 稳定排序。排除回收站、无拍摄日期和已知不可读取素材。
4. 不触发新的 AI 分析。界面不把规则候选宣传为“AI 精选”。
5. 每行可更换、编辑一句话或取消勾选；更换进入与手选相同的编辑器。
6. 底部显示“将填充 N 天，保留已有 M 天”，点击“保存所选 N 天”才写入。
7. 保存前重新检查日期空缺和素材可用性。期间被另一设备填写的日期保留新值，并报告跳过原因。
8. 部分保存失败时显示成功、跳过和失败数量，保留失败项，允许只重试失败项。

若没有可填充日期，按钮不可用并给出“本月有素材的日期都已选好”或“本月暂无可选素材”。关闭候选清单不会改变日历。

## 9. 影片制作与预览

### 9.1 选择时间

- 快捷范围：当前查看月份、当前查看年份、自选日期。
- 自选起止日期均包含在范围内，不能超过今天，最长 366 个自然日。
- 日期范围跨月或跨年时仍按日期升序拼接。
- 范围没有有效选帧时，显示“先选至少一个瞬间”；提供返回月历按钮，不创建空影片。
- 汇总展示：“31 天范围 · 23 个瞬间 · 8 天未选 · 预计 23 秒”。
- 失效选帧单独计数，并提供“去更换”。用户必须更换，或明确选择“本次跳过失效素材”后才能生成。
- 未选日期默认跳过，不生成空白一秒。影片中保留真实日期，因此跳跃日期可被理解。

### 9.2 画面设置

| 设置 | 首版选项 | 默认 |
| --- | --- | --- |
| 标题 | 最多 40 字，默认“2026 年 10 月 · 一日一帧”等 | 根据范围生成，可改 |
| 画幅 | 竖屏 9:16 / 横屏 16:9 | 竖屏 |
| 适配 | 完整画面 / 填满画面 | 完整画面 |
| 日期 | 显示 / 隐藏 | 显示 |
| 一句话 | 显示 / 隐藏 | 显示 |
| 声音 | 静音，首版不可切换 | 静音 |

- 完整画面保持原比例，空余区域用纯色背景填充；填满画面居中裁切，不拉伸。
- 背景使用生成时的主题背景色，保存到作品设置中；主题后续变化不会改动已有作品。
- 日期和文字放在固定安全区域，使用衬底保证可读；不露出精确地点或人物识别信息。
- 30 字一句话最多两行，使用固定排版区域，不横向滚动、不在导出时省略。
- 片段间直接切换，不添加片头片尾，保证 N 个选帧对应 N 秒。标题用于作品列表与文件名，不占据额外视频时长。
- 导出为 MP4，横屏 1920×1080 或竖屏 1080×1920，30 fps；不足一秒的动态素材也补足为 30 帧。

### 9.3 预览交互

- 首次进入显示首个选帧及播放按钮，用户主动播放后按保存顺序播放。
- 下方是按日期排序的片段条，点击某个片段定位，显示日期与一句话。
- 显示当前位置和总时长；支持播放、暂停、拖动进度、重播，不自动无限循环。
- 点击“编辑这一天”跳转选帧编辑器，保存后返回制作页，刷新预览并保留日期范围和画面设置。
- 范围或设置改变后，旧预览标记为待更新；新预览准备好之前不允许拿旧画面生成当前作品。
- 预览必须复用导出的适配、日期与文字规则。预览使用较低清晰度时明确标识，不能声称像素级一致。

## 10. 生成、下载与作品列表

### 10.1 生成任务

1. 点“生成影片”时，保存当次选帧、日期、片段起点、文字与画面设置的快照。
2. 显示“排队中 → 生成中 → 已完成 / 失败 / 已取消”。进度无法准确估算时显示阶段，不编造百分比。
3. 生成中允许离开页面，作品列表持续显示任务状态；返回或刷新后仍能恢复。
4. 同一用户相同内容快照与设置的重复点击复用进行中任务；已完成且文件可用时直接打开结果。
5. 生成失败显示可理解的原因，例如“10 月 3 日的视频暂时无法读取”，提供重试或返回修改。
6. 用户可以取消尚未完成的任务，取消后不出现可下载的半成品。

### 10.2 完成与作品管理

- 完成页显示播放器、标题、日期范围、有效天数、时长、画幅、生成时间和“下载 MP4”。
- 作品列表按创建时间倒序，卡片显示首个片段封面、标题、范围和任务状态。
- 下载文件名例如 `一日一帧_2026-10_23天.mp4`，处理文件名非法字符。
- 不要求开启公共访问或生成外部分享链接；首版通过下载交给用户自行分享。
- 日历后续修改时，已有作品保持生成时内容；显示“日历已更新，可重新制作”，不会自动重生成。
- “删除作品”确认后移除该任务及生成文件，保留日历选帧和原始素材。
- 成品文件丢失时显示“作品文件不可用”，可基于快照重新生成；源素材也失效时要求返回修改。

## 11. 日期归属与数据一致性

- 第一次使用时，以浏览器提供的 IANA 时区初始化日历时区；展示在设置入口，示例 `Asia/Shanghai`。不能只用 UTC 偏移代替完整时区。
- 日期、今天与未来日期判断统一使用该日历时区，不能使用服务端机器日期。
- 初始化时可修改时区。已有选帧后首版锁定时区，其他设备按已保存时区展示，避免旅行或设备切换导致日期漂移。
- 带时区的拍摄时间转换为日历时区后分日；没有时区的拍摄时间按其记录的本地日期处理，不猜测时区。具体读取方式在实现阶段核实，不能拿上传时间兜底。
- 保存选帧时固定所选日期。原照片拍摄时间后续调整不自动移动选帧，编辑器提示“拍摄日期已调整，此选帧仍保留在原日期”，允许用户移除后在新日期重选。
- 每用户每日期唯一，多设备编辑以版本校验避免覆盖。发生冲突时提示“这一天已在另一处更新”，用户重新加载后决定是否替换。
- 选帧保存素材引用和编辑参数，不复制原文件、不修改原图、不创建重复图库记录。

## 12. 异常与边界

| 情况 | 要求 |
| --- | --- |
| 源照片进入回收站 | 日历显示失效，禁止预览源素材；恢复后重新校验，满足条件即可恢复有效 |
| 源素材永久删除或失去访问权限 | 保留日期和失效状态，候选列表不泄露原素材；用户可替换或移除 |
| 外部图库路径暂时离线 | 区分暂时不可读取与删除，允许重试，不自动移除记录 |
| 动态配套文件失效 | 提示改用静态照片，并由用户确认；不静默改变原选帧模式 |
| 批量填充期间新照片导入 | 当前候选清单保持不变，提供刷新候选；刷新不覆盖用户已修改的项 |
| 生成时素材失效 | 任务失败并指明相关日期，不静默减少影片天数 |
| 生成期间日历被修改 | 当前任务按快照生成；完成后标识可重新制作 |
| 完成后源素材删除 | 已生成影片作为独立作品保留，作品详情说明删除源照片不会同步删除作品；用户可单独删除作品 |
| 生成期间源素材被删除或失权 | 在生成和发布结果前再次校验；失败后清理临时成品，不发布包含不可访问素材的新作品 |
| 网络断开 | 保留当前未提交编辑，恢复后重试；重新校验版本，不自动覆盖 |
| 同一天数千张照片 | 候选分页、缩略图懒加载、只加载当前预览动态文件 |
| 闰年与跨年范围 | 正确包含 2 月 29 日，范围按实际日期枚举，不用固定 365 天推算 |
| 导出能力不可用 | 月历仍可选帧；制作页明确说明当前实例暂不支持影片生成，不让用户等到提交后才发现 |

## 13. 文案、主题与可访问性

- 主文案：“每天留下一个代表瞬间”。
- 空日提示：“这一天还没有选帧”；无素材提示：“这一天没有可用素材”。
- 对缺口使用中性文案，避免“断签”“补救”“失败一天”等措辞。
- 主题强调色跟随系统主题，暗色下月历、弹窗、输入框和警示状态均保持可读。
- 所有日期按钮有包含日期和状态的可访问名称，例如“2026 年 10 月 3 日，已选视频”。
- 日期、播放、片段起点和保存可通过键盘操作，弹窗关闭后焦点返回触发位置。
- 页面默认不自动播放，遵循减少动态效果偏好；状态不只靠颜色区分。
- 动态区域显示加载状态与失败重试，避免只出现永久黑屏。

## 15. 实现前需核实的能力

以下属于技术核实，不改变以上产品规则：

- 现有拍摄时间的存储与时区语义，避免前后端分日不一致。
- 浏览器对现有视频格式的解码支持，以及服务端统一转码可用性。
- Live Photo 动态文件访问方式、素材可用性检查和片段定位精度。
- 后台任务、进度通知、生成文件存储与清理策略能否复用现有能力。
- 导出字体、主题背景与文字安全区域在各部署方式下的一致性。

数据库如需新增模型，按仓库约定提供 PostgreSQL 与 SQLite 两套迁移；接口遵循统一响应结构。实施测试使用仓库统一测试入口，按选帧状态、日期、权限、任务和媒体生成风险选择测试范围。

## 16. 建议交付顺序

1. 月历、年度总览、照片手选与编辑，验证日期归属和交互。
2. 视频与 Live Photo 一秒片段编辑、批量填充。
3. 影片预览、后台生成、下载与作品管理。
4. 完整验收：预览与成片一致、并发、素材失效、权限及移动端。

以上分步属于实现顺序。首版完整交付必须包含选帧到成片下载的闭环。
