# REQ-206 照片时间浏览实现与验证

日期：2026-10-27  
需求：[照片年月日浏览与时间排序](photo-timeline-year-month-day-prd.md)  
交付形式：源码工作区改动，未提交、推送或创建 PR。

## 实现结果

- 主照片页增加年/月/日切换与年→月→日下钻；年/月概览使用完整筛选结果的数量和稳定月份封面。
- 复用现有日画廊、虚拟布局、缩略图与选择状态，切换时保持照片 ID，定位后恢复可见位置与焦点。
- 照片时间、添加时间均为倒序，后端统一分组和排序口径，以 ID 为次级排序键；现有拍摄年份筛选不改变含义。
- 切换排序先准备目标数据再替换画面；年/月视图只查询统计与锚点，进入日视图才加载目标月份。并发月份请求复用同一 Promise，过期结果不能替换新意图。
- 缺失时间在末尾独立显示“时间未知”。处理空结果、清除筛选、失败重试、浏览器前进后退、账号偏好、减少动态效果。
- 添加时间复用 `upload_time`；未修改其写入逻辑。照片详情仍显示和编辑照片时间。
- 未修改 ORM 模型，无数据库迁移。
