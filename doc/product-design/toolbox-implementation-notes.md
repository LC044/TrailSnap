# 工具箱 P0/P1 首版交付记录

日期：2026-11-06。依据 `toolbox-redesign-prd.md` 实现，按用户要求跳过需求平台。
本记录描述当前本地代码及实际验证结果，不代表全部 PRD 验收项已完成生产环境验收。

## 已实现

- 新工具箱首页，保留原六项工具路由；相册归类作为独立入口。
- 整理、命名、清理、拍摄信息修复统一使用“范围 → 规则 → 真实预览 → 确认执行”。
- 相册、实际目录、日期筛选、手选影像、主动选择全部图库。默认无范围，服务端不接受空来源。
- 日期、媒体类型和排除项独立于整理策略；同项按照片 ID 去重，目录使用真实路径边界与存储权限校验。
- 移动或复制文件；保留源目录层级再追加规则，或重新归档；最多三级日期、地点、人物、分类组合。
- 按相同分组规则创建普通相册，不移动原文件。
- 服务端保存自定义模板及整理方案，支持默认命名模板、最近五套有效命名配置、导入导出及账号隔离。
- 未执行编辑保存为本地规则草稿，恢复草稿不默认覆盖模板；不保存待处理范围。
- 变量在光标位置插入，重复变量全部替换；未知变量和非法模板阻止预览。
- 持久化预览计划及逐项明细，冻结目标名称；30 分钟有效，执行前显式确认。
- 预览重名避让，执行时目标被占用则失败，不覆盖；每项核验源路径、文件指纹及影像信息。
- 同计划重复确认不创建第二个任务；活跃计划之间检查影像及路径冲突。
- 任务历史、逐项进度、停止后续项目、安全重试、CSV 清单导出。
- 移动和重命名在 24 小时内有条件撤销，撤销也需预检及确认。
- 多分组复制按输出记录成功或失败，安全重试仅补失败输出，重复预览跳过已生成的有效副本。
- 清理使用已有哈希、向量或评分，默认不勾选；范围外仅作参考；完全重复组在确认及删除前核对保留项。
- 清理复用回收站逻辑；拍摄信息修复支持 JPEG/WebP 的 EXIF 时间与设备写入。
- 时间自动修复保留文件名识别能力；EXIF 成功后同步哈希、大小、EXIF 文本、条件相册和旅程任务。
- EXIF 替换前保留原片备份，数据库提交失败时补偿；若文件遭后续外部改写，保留备份供人工核对，不强行覆盖。
- 照片多选、普通相册、文件夹浏览器均有工具入口。同名存储根目录不能通过显示名称静默选中。

## 首版边界

- 普通计划最多 50,000 项，范围内存枚举读取上限为 50,001 项；相似比较最多 3,000 项，尚非异步大规模预览。
- 范围预览分页会重新统计；相册搜索当前仅加载前 1,000 个相册再过滤，尚无服务端搜索分页。
- 文件操作只支持静态照片；视频及检测到的关联文件跳过。关联文件检测不等于覆盖所有厂商的动态照片格式。
- 没有复制撤销、EXIF 通用撤销、完整目录树预览、搜索全部匹配结果入口、90 天日志清理机制。
- 文件与数据库不能整体原子提交；程序中断中的项目保守标记需人工核对，未做真实断电、服务重启恢复或并发外部写入专项验收。
- 幂等历史查询目前最多回看每个影像最近 100 条相关记录。
- 原文件被外部修改时用尺寸和修改时间检验，不是全文件内容锁或跨进程写入锁。
- 未执行 PostgreSQL 实库迁移测试、正式图库文件变更端到端测试、真实手机软键盘验收；未覆盖全部工具与全部主题色的视觉矩阵。
- PRD 的 AC-01 至 AC-26 有相应实现，但上述测试不等同于逐项完整端到端验收，尤其 AC-24 的软键盘与完整预览页面仍待联调。
