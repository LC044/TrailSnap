# 3D 足迹地图

入口：位置相册工具栏的「3D 足迹」，或直接访问 `/footprint`。页面需要登录，使用当前用户的真实照片，不内置演示足迹。

## 浏览与回放

- 2D：俯视平面地图，可自由平移和缩放；3D：聚焦中国的三维透视，可自由平移、倾斜和缩放；地球：完整全球视角，拖动用于旋转地球，滚轮和缩放按钮始终沿地心方向缩放并保持球体居中。三个模式共用年份、城市、照片和图层状态。
- 旅行连线按照片时间推断城市访问顺序，并非导航 GPS 轨迹。同一次访问使用一个稳定坐标作为进入和离开的共同锚点，保证单次旅程内首尾相接；相邻照片超过 7 天时切分为不同旅程，避免把相隔数月或数年的地点误连成一次出行。
- 年份选择、底部年份轴、统计柱状图可筛选时间。搜索框检索当前年份的足迹城市。
- 点击城市光点、地图照片卡片或城市排行，地图飞向该城市，侧面板显示到访信息和照片；照片按 24 张分页加载并接入现有照片查看器。
- 「旅程回放」按拍摄时间依次突出地点连线，可暂停、拖动进度以及切换 1× / 2× / 4×；「年份巡游」逐年切换足迹。
- 图层菜单控制城市照片、旅行连线、照片热力、省份边界和三维地形。全球模式支持自动旋转。
- 全屏按钮调用浏览器 Fullscreen API，同时隐藏导航、统计和时间轴，保留地图控制与「退出沉浸」。不支持原生全屏的浏览器使用占满视口的沉浸模式；Escape 可恢复界面。
- 移动端统计默认收起，通过顶部统计按钮展开；地图、搜索、时间轴和全屏仍可使用。

## 技术与数据口径

前端使用 Vue 3、Pinia、CesiumJS 和 ECharts。Cesium 独立懒加载，Workers、Widgets 和地球纹理随前端构建分发，不依赖脚本 CDN 或 Cesium ion 账号。Cesium 的二维与三维模式复用同一个 Viewer。

底图优先使用当前用户配置的天地图卫星影像，由现有服务端 map-proxy 携带受限访问令牌请求；没有地图配置或影像请求失败时显示内置 Natural Earth 地球。地形采用 ArcGIS WorldElevation3D，按需开启；不可用时保留球面，并提示状态。影像、地形来源信息保留在地图署名处。

照片经纬度按 WGS84 使用。天地图不能按高德地图的 GCJ-02 坐标处理。行政区边界复用 `/medias/geojson?level=province`，没有新增 GIS 数据库扩展。

新增两个 API，均经过用户鉴权并返回 `BaseResponse`：

| 接口 | 参数 | 用途 |
| --- | --- | --- |
| `GET /locations/footprint` | `year`、`bbox`、`max_points` | 年度统计、城市聚合、地点连线、年份趋势 |
| `GET /locations/footprint/photos` | `city_id`、`year`、`skip`、`limit` | 城市照片分页 |

所有查询按 owner 隔离并排除已删除照片。`photo_count` 包含无 GPS 照片；`gps_photo_count` 是有有效 GPS 的照片数。城市数以有效 GPS 照片的真实城市字段为准，未知城市按坐标网格保留足迹，不混成一个“未知城市”。城市位置取真实照片坐标，而不是可能落在错误位置的经纬度平均值。

城市标识包含国家、省份和城市的完整组合，避免同名城市串图。到访次数表示连续访问片段：同地点拍摄间隔超过七天会开启新片段；无拍摄时间的数据不用于推断到访顺序。连线仅连接相邻片段中的照片地点，超过七天不连线，相同时间不推断行进方向。它们**不代表实际道路、航班或 GPS 导航轨迹**；原位置页面的 GPS 轨迹视图继续保留。

年份使用当年 1 月 1 日至次年 1 月 1 日的左闭右开区间。总览与趋势在数据库聚合，不受地图点位抽样或可见区域裁剪影响。前端默认请求最多 800 个城市和 800 条连线；大型相册在镜头移动后按视野补充加载。路线抽样保留原始相邻连线，不把跳过的片段拼成新路线。

## 性能与离线

- 城市聚合、轨迹抽样在后端完成；行政区简化和弧线坐标计算放入 Web Worker，失败时使用兼容计算。
- 地图按需要请求渲染，限制像素比、瓦片缓存和照片卡片数量；照片卡片按屏幕距离避让，每次最多并行加载三张封面。
- 年份和照片请求可取消，并阻止旧响应覆盖新筛选。城市照片只在打开详情后获取。
- 私有足迹快照按服务器、用户和年份分开缓存，最多五份、有效期一天，退出账号时随现有私有缓存清理。断网时标明快照时间；重新联网后重新请求数据。
- PWA 按需缓存随应用分发的公开地球资源；不缓存第三方服务瓦片或照片 API。离线不保证尚未访问区域的高清影像、照片或地形可用。
- 隐藏页面时暂停播放和旋转，停止渲染循环；离开路由时销毁 Viewer、Worker、监听器、计时器和未完成请求。
- 地图面板采用固定暗色的沉浸视觉；强调色和边界跟随全局主题，保留键盘焦点指示，并尊重减少动态效果的系统设置。

## 验证方式

后端新增测试：`package/server/tests/unit/test_footprint.py`，覆盖用户隔离、删除状态、GPS 校验、年界、时间缺失、同名城市、跨日期线 bbox、七天断线、抽样及响应格式。

统一入口：

```powershell
pwsh tests/scripts/run-tests.ps1 -Layer unit -Level smoke -Component server -Scope album
```

前端构建：在 `package/website` 执行 `pnpm build`。浏览器验收使用本地已有账号，只读取照片数据，不启动会删除账号或清空数据库的测试夹具。截图与临时验收记录保存在 `output/playwright/footprint/`。

外部技术参考：[Cesium 影像接入](https://cesium.com/learn/cesiumjs-learn/cesiumjs-imagery/)、[Cesium 场景与按需渲染](https://cesium.com/learn/cesiumjs/ref-doc/Scene.html)、[ArcGIS 地形接口](https://cesium.com/learn/cesiumjs/ref-doc/ArcGISTiledElevationTerrainProvider.html)。
