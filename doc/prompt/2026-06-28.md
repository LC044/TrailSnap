# 本周开发计划 · 2026-06-28

> 版本号：v0.18.0（拟定，以 release 日最终确认为准）
> 发布日：2026-06-28（周六）
> 主题：**位置相册 · 发现之旅** —— 让「位置相册」从单纯的照片集合，升级为可被阅读、可被发现、可被分享的旅行洞察。

## 一、本周主题

参考 issues：`#55 #56 #57 #58 #59 #60 #62 #63 #64 #65`（一条完整的 `feat(location)` 产品线），结合上周已收尾的 `#66 景区层级嵌套` 做深度扩展。

**核心目标**

1. 用户进入「位置」模块后，能在一屏内**看到旅行的全局概览**（仪表盘）。
2. 地图视图从「标记点」升级为**带密度热力的可视化**。
3. 增加多种**筛子和发现入口**：季节/月份、重游、近邻、行程聚合、轨迹回放，让用户能"翻出"自己拍过的老地方。
4. 每个发现结果都有**可消费的页面/卡片**，而不是只返回数据。

**非目标**

- 不做完整的年度报告（下一版再做）。
- 不做朋友圈九宫格、自动旅行日志（#44 / #45 留到后面单独排期）。
- 不做对外分享链接（#61 安全审计较重，本周不排）。

### 1. 旅行统计仪表盘（P0）

**入口**

- 位置模块顶部 Tab：`位置 / 景区 / 仪表盘`
- 首页"数据洞察"卡片直链

**页面布局（自上而下）**

1. **核心数字带**：四张并排大数字卡
   - 总旅行距离（km）
   - 到访：省 / 市 / 区 / 景区 数量（点击穿透到对应列表）
   - 旅行连续天数（streak）
   - 最远一次旅行（地点 + 距离）
2. **月度出行偏好**：雷达图（12 个月维度，鼠标悬停显示该月照片数、代表景点）
3. **足迹半径图**：以常驻地（可手动设置/自动推断为停留最久的城市）为圆心，显示最远到达点的距离圈，可缩放
4. **年度趋势图**：折线图，X 轴年份，Y 轴累计到访省/市/区/景区数；可切换粒度
5. **Top 榜**：右侧两列
   - "最常去的地方"（按城市/景区聚合）
   - "最远的一次旅行"（按单次行程最远距离）
6. **空状态**：当数据不足（照片 < 5）时，给出引导："再多拍几张带位置的照片，仪表盘就会丰富起来"。

**交互要求**

- 数字带支持点击穿透：距离→"距离相关行程"列表，省/市/区→对应筛选。
- 图表与下方位置列表双向联动：图表上点击某月/某年，列表自动筛选。
- 提供"时间范围"切换器：本年 / 去年 / 全部。
- 提供"导出当前仪表盘为图片"按钮（带品牌色边框，可分享）。

**验收**

- 数据来源：基于已有 `photo_metadata`、`timeline_nodes` 即可计算，不要求新增采集。
- 所有数字在数据变更（如新增照片）后能在下一次进入页面时自动刷新。
- 移动端：数字带折成 2×2；雷达图与趋势图保持可读；Top 榜可滑动。
- 暗色模式下，图表配色使用主题色（`primary-*`），不出现"白底"。

### 2. 旅行热力图（P0）

**入口**

- `LocationMap.vue` 右上角模式切换：`标记模式 / 热力模式`

**页面与交互**

- 切到热力模式后，原有点位标记淡出，平滑过渡到热力层。
- 颜色由"冷到暖"映射照片密度（具体色阶走主题色板，避免引入新色系）。
- 图例条：左侧竖向色阶条 + 标注"低 / 中 / 高"。
- 缩放自适应：低 zoom 聚合到城市级，高 zoom 显示街区级密度。
- 顶部保留原"城市/景区筛选"，与热力叠加生效。
- 鼠标悬停热力点时，弹出小气泡显示"该区域 N 张照片"。

**验收**

- 切换模式无白屏、无重新加载。
- 当筛选范围为空（无照片）时，热力层直接隐藏，给出空状态提示。
- 在 1000 张照片以上的库中保持 60fps 滚动。
- 支持"按密度重排名"：切到热度 Top 10 列表视图（可选次级视图）。

### 3. 季节 / 月份快捷筛选（P0）

**入口**

- `LocationList.vue` 筛选栏新增独立区域，置于"年份"和"日期范围"之上。

**页面与交互**

- 季节快捷按钮组（segmented control）：`全部 / 春 / 夏 / 秋 / 冬`
  - 季节定义：3–5 月=春，6–8 月=夏，9–11 月=秋，12–2 月=冬。
- 月份多选（chip 形式）：1–12 月，点击 toggle，支持多选。
- 与"年份筛选"和"自定义日期范围"**叠加生效**（取交集）。
- 选中后筛选条件以"面包屑"形式出现在列表上方，可单独清除某项。
- 列表上方新增一个微缩图："季节分布柱状图"，4 个柱，点击柱体直接应用对应季节筛选。

**验收**

- 季节/月份选择与"自定义日期范围"互相约束：当范围已锁死某月时，季节按钮自动高亮对应季节。
- 选择状态在切换页面/退出后保持（写入本地存储）。
- 暗色模式下，segmented control 与 chip 颜色跟随主题色。

### 4. 重游分析（P1）

**入口**

- 位置模块左侧菜单新增项：`重游`
- 仪表盘"最常去的地方"Top 榜里点击地点，可穿透到「重游详情」。

**页面与布局**

- 顶部 4 个数据卡：重游地点数（≥2 次访问）、累计访问天数、跨度最久的地点、跨度最短的地点
- 主体：重游卡片列表（按访问次数降序），每张卡片包含：
  - 地点名 + 城市/景区徽标
  - 访问次数
  - 时间跨度：首次到访 / 最近到访（带具体日期）
  - 累计访问天数
  - 代表性照片（取评分最高的 1 张做封面，点开进入相册）
  - "高亮重游 3 次以上"徽章
- 列表右侧提供筛选：访问次数（≥2 / ≥3 / ≥5）、时间范围、季节。

**交互**

- 卡片点击展开：内嵌时间线，标注每次到访的具体日期、停留天数、当次照片数。
- 卡片右上角"在地图看"按钮：跳到地图并自动定位到该地点。
- 顶部"季节分布条"：直方图显示该地点的访问集中在哪些季节（与季节筛选呼应）。

**验收**

- 至少能稳定展示 5 张以上的重游卡片（不足时显示空状态 + 引导）。
- 数据按"访问天数"和"访问次数"两种排序可切换。
- 卡片内的代表性照片支持懒加载。

### 5. 近邻发现（P1）

**入口**

- Lightbox 照片详情面板新增"附近照片"区块（在「元数据」「标签」之后）。
- 照片浏览页右键菜单新增"在附近发现"项。

**页面与交互**

- 区块标题："同位置，不同时间的照片"
- 副标题：自动根据当前照片经纬度 + ±0.01° 范围匹配，排除同一天，按时间排序。
- 横向时间轴：每张照片一个圆形节点，按时间从左到右排列；高亮与当前照片时间最接近的 1–2 张（带"距离 X 年/月"标签）。
- 点击节点：替换 Lightbox 当前照片，并自动滚动到对应时间轴位置。
- 时间轴可拖拽（鼠标左右滑动 + 触屏滑动）。
- 没有匹配时显示空状态："这张照片的附近，暂没有其他时间拍过的照片"。

**验收**

- 匹配范围可视化：在 Lightbox 内嵌的小地图上画出范围圈，圈内已拍过的照片用空心点标出。
- 时间轴节点支持键盘 ← / → 切换。
- 与"位置专辑"模块联动：点击"在附近发现"也可跳转到位置模块下对应的"此地点"页面。

### 6. 智能行程聚合（Trip，P2）

**入口**

- 位置模块 → Timeline 视图上方新增视图切换：`日 / 行程`
- 切到"行程"模式后，原本按天拆分的节点合并为 Trip 卡片。

**页面与交互**

- Trip 卡片样式：
  - 顶部：行程名（默认取主要城市/景区名，可手动重命名）
  - 起止日期 + 总天数
  - 覆盖城市/景区（chip 形式，超过 3 个折叠为 "+N"）
  - 照片总数、代表照片（封面 + 2 张缩略图）
  - 右侧"展开"按钮
- 展开后内嵌每日时间线，与现有 timeline 节点一致。
- 不同 Trip 用不同色块区分（色块取自当前主题色板的浅/中/深三档，避免引入新色）。
- 顶部"行程列表 ↔ 地图"切换：地图模式下，地图按 Trip 着色，路径粗细代表照片数。

**验收**

- 合并规则可调：默认"同地区 < 100km"且"时间间隔 < 3 天"才合并。
- 行程可手动拆分/合并（编辑按钮弹窗）。
- 当用户没有可识别的多日行程时，给出空状态引导。

### 7. 轨迹回放动画（P2）

**入口**

- `LocationTrajectoryView.vue` 顶部新增"播放"按钮（在筛选/导出按钮旁）。

**交互**

- 工具栏：播放/暂停、速度（1x / 2x / 4x）、进度条（可拖拽跳转）。
- 播放中：地图按时间顺序逐步绘制轨迹线，节点位置弹出照片缩略图气泡（自动 2 秒后淡出）。
- 已走过的轨迹线用主题色深色，未走过的部分用浅色。
- 移动端：默认自动播放，触屏按下暂停。
- 进度条上方显示"当前时间 / 总时间"，时间格式为 `YYYY-MM-DD`。
- 结束时自动暂停，并弹出"重播"按钮。

**验收**

- 1x 速度下，整段行程回放时长 = 实际拍摄天数（压缩为可观看时长），但节点切换节奏自然。
- 进度条拖拽可跳到任意时间点，地图与气泡同步刷新。
- 播放过程中可暂停/继续，且不会丢失已走过的轨迹样式。

## 四、跨模块注意事项

- **主题色一致性**：本周所有新页面/图表/徽章都使用 `primary-*` 主题色类，遵循既有 `useTheme` 规范。
- **暗色模式**：所有新增数字卡、雷达图、热力层必须有暗色变体；不出现"白底"图表。
- **空状态**：每个新页面都要有可读的引导文案，不要裸露"暂无数据"。
- **响应式**：所有页面在 375px 移动端宽度下仍可用，关键数字、Top 榜、卡片网格自动折行。
- **键盘可达**：仪表盘、Lightbox 附近照片、时间轴、轨迹回放进度条都需支持键盘操作（Tab 焦点环、←/→ 切换、Space 播放/暂停）。
- **多语言**：仪表盘、统计、重游等中文文案走 i18n 占位，本周先落地中文。

## 五、风险与说明

1. **数据量级**：仪表盘与热力图涉及全表聚合，若照片数 > 50k，可能需要缓存层，本周先做"按需计算 + 短缓存"，观察性能再决定是否要做物化视图。
2. **行程聚合算法**：Trip 合并阈值（100km / 3 天）需要和 PM 一起对真实数据调参，本周先按默认值上线，发布后根据反馈迭代。
3. **热力图渲染**：天地图热力插件在不同主题色下颜色映射需要逐主题校对，避免出现"看不见"或"过亮"。
4. **Lightbox 性能**：近邻发现一次性返回的照片不宜超过 50 张，超出时分页加载。
