# REQ-159 票据识别回归

修复范围：无“站”后缀及箭头站名、具备布局证据的新站、标签/证件姓名、繁简车厢座位、明确年份、铁路文字校正票种、火车接口类型过滤，以及单检测框缺车次时的一次整图 OCR 补充。

## 日期与补充策略

- 年份必须来自选中的行程日期，或相邻且布局一致的独立年份块。广告、活动、经停说明不参与日期选择。
- 火车 AI 结果无年份时保留月日；火车接口和机票解析器为兼容现有表单使用当前年份，并返回 `year_source: inferred_current_year`。这仍需用户核对跨年行程，不能视为图片识别出的年份。火车接口明确年份标记为 `explicit`。
- 仅单检测框、火车类型且缺车次时额外 OCR 一次。只补车次，不补其他字段；多检测框不做整图补充。
- 双车次必须有出发站对应的变更说明才能消歧。对于“自当前车站起车次号变更为…”提示，用提示上方最近的站名及有界距离关联。关联不可靠时留空。补充失败保留局部结果。
- 检测为机票时，只有铁路车次加铁路专有文字且没有明显航空文字才改用火车解析器。火车接口拒绝显式非火车类型；兼容未提供类型但具有铁路字段且无航班号的旧结果。
