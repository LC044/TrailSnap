# 照片灯箱快捷键体系（PhotoLightbox Keyboard Shortcuts）

## 功能描述

为 `package/website/src/components/PhotoLightbox.vue` 补齐键盘快捷键，覆盖灯箱工具栏的 9 个高频操作（缩放、原图、元数据侧栏、OCR、添加、删除、下载、编辑、关闭），并新增一个 `useHotkeys` 组合式统一管理快捷键生命周期，让现有 `OnThisDay.vue` / `PhotoEditor.vue` / `useModalBack.ts` 中散乱的 `document.addEventListener('keydown', ...)` 样板可以收敛。

参考 GitHub Issue #70（Lightbox 键盘快捷键）的上游需求。

## 功能价值

- **真实痛点**。当前灯箱工具栏是 12 个圆形按钮横排（`PhotoLightbox.vue` L7-67），用户每次切图/缩放/查看元数据都要移到右上角点 4-8 次。在相册/搜索/时光轴/相似清理等场景下，灯箱是核心查看路径，键盘可达性的缺失是高频摩擦。
- **与既有产品对标**。Google Photos、Apple Photos、Flickr、Immich、PhotoPrism、Lightroom 都有完整快捷键（←/→ 切换、Space 自动播放、I 信息、D 下载、Del 删除等），自托管相册用户对此有明确预期。
- **全栈收益**。`FlatPhotoGallery.vue` 在 PhotosPage、AlbumDetail、PeopleDetail、Search、RecycleBin、Toolbox 多个视图中共享同一灯箱入口；一处落地，七处受益。
- **基础设施投资**。当前 `OnThisDay.vue` L213、`PhotoEditor.vue` L379、`useModalBack.ts` 都各自手写 `onMounted`/`onUnmounted` 增删 keydown 监听。新增 `useHotkeys` 组合式把这些重复样板收敛，并天然支持优先级栈（弹窗打开时屏蔽 Lightbox 快捷键、Lightbox 打开时屏蔽全局快捷键）。
- **可发现性设计成本低**。工具栏按钮的 `title` 属性已存在（如 L33 `title="下载图片"`），扩展为 `title="下载图片 (D)"` 即可，零额外 UI。

## 功能细节

### 页面描述

**第一阶段：核心灯箱快捷键**（`PhotoLightbox.vue`）

| 按键 | 行为 | 现有入口 |
| --- | --- | --- |
| `←` / `→` | 上一张 / 下一张 | L102 / L109 `prev` / `next` |
| `Space` | 下一张（视频/Live Photo 优先切换播放状态） | - |
| `+` / `=` | 放大 | L18 `zoomIn` |
| `-` / `_` | 缩小 | L17 `zoomOut` |
| `0` | 重置缩放 | - （需新增 `resetZoom` 调用入口） |
| `I` / `M` | 切换元数据侧栏 | L42 `toggleSidebar` |
| `O` | 切换 OCR | dropdown `ocr` |
| `D` | 下载 | L28 `downloadImage` |
| `E` | 进入编辑（仅图片类型） | L33 `enterEditMode` |
| `Shift+O` | 切换原图 | L40 `toggleOriginal`（与 OCR 用 Shift 区分） |
| `Delete` / `Backspace` | 删除 | L37 `handleDelete` |
| `A` | 添加到相册 | dropdown `addToAlbum` |
| `P` | 添加到人物 | dropdown `addToPerson` |
| `F` | 移动到目录 | dropdown `moveToFolder` |
| `?` / `H` | 切换快捷键提示层 | - |
| `Esc` | 关闭灯箱 | L3（已存在） |

**第二阶段：发现性 UI**

1. **首启提示层**。灯箱打开后，左下角浮现半透明 toast：`←/→ 切换 · +/- 缩放 · I 信息 · D 下载 · Del 删除 · ? 查看全部`，3 秒后渐隐；当用户首次按下 `?` 永久关闭后不再浮现，写入 `localStorage.trailsnap_seen_shortcut_hint`。
2. **工具栏 hover 提示**。所有工具栏按钮的 `title` 从 `"下载图片"` 扩展为 `"下载图片 (D)"`，沿用 `focus-visible:ring-2 focus-visible:ring-primary-500` 焦点环主题色。
3. **快捷键速查面板**。`?` 键弹出一个 `el-dialog`（不打断当前查看、按下 `?` 或 `Esc` 关闭），以三列网格列出全部快捷键，分组「导航 / 缩放 / 编辑 / 媒体 / 信息」。沿用 `bg-white dark:bg-gray-900` + 主题色高亮。

**第三阶段：`useHotkeys` 组合式**（`composables/useHotkeys.ts`）

签名参考 `useModalBack` 的现有写法（`composables/useModalBack.ts`），但更通用：

```ts
useHotkeys([
  { key: 'ArrowLeft', handler: prev, when: () => hasPrev.value && !isEditing.value },
  { key: 'ArrowRight', handler: next, when: () => hasNext.value && !isEditing.value },
], { priority: 100, enabled: () => visible.value })
```

要点：
- `priority` 字段实现快捷键栈：弹窗（如添加相册、OCR 提示）打开时 push 一个更高优先级的层，全局快捷键自动屏蔽。
- `enabled` 字段统一禁用，无需在 `onMounted` 时写散乱判断。
- `when` 字段就地判定上下文（灯箱打开中、isEditing 中、空 input 焦点中跳过），与 PhotoEditor 的 L347 风格保持一致。
- 自动 `onUnmounted` 解绑，避免 OnThisDay / PhotoEditor 当前的散乱模板。

**第四阶段：迁移现有散乱监听**

- `OnThisDay.vue` L213-217 的 `window.addEventListener` 改为 `useHotkeys`。
- `PhotoEditor.vue` L347 改为 `useHotkeys`（因为 Editor 是 Lightbox 内的子组件，要确保 `priority: 200` 高于父灯箱）。
- `useModalBack.ts` 内部从 `document.addEventListener('keydown', ...)` 改为 `useHotkeys({ key: 'Escape' }, { priority: 150 })`。

### 页面风格

- **沿用主题色**。提示 toast 背景 `bg-gray-900/80 dark:bg-gray-100/90` 配 `text-white dark:text-gray-900`，分隔点用 `text-primary-500` 高亮键名。速查面板的「聚焦态」按键使用 `bg-primary-500 text-white` 圆角徽标。
- **暗色适配**。toast 与速查面板同步支持 `html.dark` 切换，遵循 `text-gray-500 dark:text-gray-400` 配对模式（避免 lightbox 内部出现 `bg-white` 突兀块）。
- **焦点环**。速查面板里的可点击分组标题使用 `focus-visible:ring-2 focus-visible:ring-primary-500 focus-visible:ring-offset-2`，跟随主题。
- **单灰色族**。toast 与速查面板统一用 `gray-*`，不与灯箱的 `bg-black/95` 主背景交叉出暗色接缝。
- **零硬编码品牌色**。所有强调色走 `primary-*` utility 类和 `var(--theme-primary)`，跟随 sky / emerald / violet / rose / amber 五套主题自动切换（参考 `composables/useTheme.ts`）。

### 验收与回归

- E2E：`tests/e2e/` 新增 `lightbox-shortcuts.spec.ts`，用 Playwright 触发 `←` / `D` / `Del` 并断言 DOM 变化。
- 手动回归：所有现存灯箱入口（PhotosPage / AlbumDetail / PeopleDetail / Search / RecycleBin / Toolbox）逐一确认快捷键生效且不与 Element Plus 内部快捷键冲突（`el-select` / `el-dialog` 的 Esc 应优先于灯箱的 Esc）。
- 性能：`useHotkeys` 注册的事件 listener 数应少于 1 个 `document` 级别（用事件委托），避免每开一次灯箱就增绑 N 个 listener。
