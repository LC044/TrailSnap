# 新功能建议：照片收藏（Favorites / 喜欢）

> 对应 GitHub Issue [#67](https://github.com/LC044/TrailSnap/issues/67)「照片收藏：手动标记喜欢与精选照片管理」。  
> 在前后端仓库中 `favorite` / `is_favorite` / `isFavorite` / `liked` 关键字均为零命中（已用 ripgrep 验证 `package/website/src` 与 `package/server/app`），目前完全没有这个能力。

## 功能描述

给单张照片打一个最轻量的"喜欢"标记，并提供一站式的"我的收藏"浏览、筛选与发现路径。范围刻意保持小而精——只做一个布尔字段、一个切换端点、一个一级页面、两处入口，以及与现有快捷访问/相册封面/年度报告的浅层联动。

具体包含六块：

1. **数据模型**：在 `photo` 表新增 `is_favorite boolean NOT NULL DEFAULT false` + `favorited_at timestamptz NULL`（后者用于按时间排序 + 未来可能的"最近收藏"快捷入口）。Alembic 生成迁移即可。
2. **后端 API**：
   - `POST /api/medias/{id}/favorite` 切换状态，返回 `{is_favorite, favorited_at}`。
   - `GET /api/medias?only_favorite=true&page=1&page_size=60` 已有的列表查询加一个 `only_favorite` 过滤参数（CRUD 层加一行 `if only_favorite: q = q.filter(Photo.is_favorite == True)`，零破坏性）。
   - `GET /api/stats/favorites/overview` 简单聚合：总数、本月新增数、按相册/位置/人物的 Top 3 分布。
3. **Lightbox 顶部工具栏新增爱心按钮**：放在 `Download` 和 `Edit` 之间（`PhotoLightbox.vue` 第 36-50 行那一排圆形按钮），未收藏时用 `Heart` 描边 icon + `text-white/90`，已收藏时换成实心 `Heart` + `text-rose-500` 并播一个 200ms 的 scale 弹跳动效（`@keyframes` 在 scoped 样式里写就行）。点击调切换端点；失败时回滚 UI + `ElMessage.error`。
4. **`FlatPhotoGallery` 批量操作栏新增"收藏 / 取消收藏"按钮**：在 `add-to-album` 和 `download` 之间（参考 L31-L49 的结构），多选 N 张后调用 `POST /api/medias/batch-favorite`（后端一次性更新，返回新计数）。空选时 disabled。
5. **新页面 `/favorites`**：复用 `RecycleBinPage.vue` 的"扁平画廊 + Lightbox + 顶栏"骨架（299 行那个结构非常合适），把"删除"换成"取消收藏"，加一个右上角 `el-segmented` 切换"全部 / 按相册 / 按位置 / 按人物 / 按时间"，底部加一行小卡："本周新增 N 张" 简单统计。
6. **侧边栏入口**：
   - `Sidebar.vue` 的 `navLinks`（L302-L306）`照片` 与 `相册` 之间插入一行 `{ label: '收藏', href: '/favorites', icon: Heart }`。  
   - `HomePage.vue` 的快捷操作区（紧贴 `HeatmapSection` 上方）新增一张 2×2 紧凑小卡，标题"我的收藏" + 数字徽标（数据来自 `/api/stats/favorites/overview` 的 `total`），点击跳 `/favorites`。

## 功能价值

1. **零成本补齐"用户期待"曲线**。本地照片库里"喜欢/星标"是几乎所有同类应用（Google Photos、Apple Photos、Immich、Pixieset）都有的基础能力，但当前 `rg "favorite" package/website/src` 与 `rg "favorite" package/server/app` 都返回 0 行结果。补这一项的边际成本极低（一个布尔字段、两个端点、一个新页面），但能让产品跨过"功能完备 vs. 自托管玩具"那条线。
2. **与现有 7 个特性无缝叠加**：
   - 智能相册：选"封面"时下拉默认显示已收藏的照片（`AlbumDetail.vue` 的 `coverPhoto` 候选列表加 `is_favorite` 优先排序）。
   - 快捷访问（`Sidebar.vue` L215-235）：加一个"最近收藏"的虚拟分组，自动把 `favorited_at` 最近 5 张列出。
   - 朋友圈九宫格（Issue #45）、朋友圈分享图（Issue #60）：选图时默认勾选已收藏照片——社交流的"挑片"步骤彻底省掉。
   - 年度报告（`views/annual-report/index.vue`）：新增"今年你收藏的 N 张"插图，复用 `dominantColor` 拼九宫格，无需新增 AI 能力。
   - 智能相册推荐（Issue #48）：推荐候选"专属于你的 N 张精选"是天然钩子。
   - Agent 工具（`service/agent/tools.py`）：新增 `add_to_favorites(photo_id)` 与 `list_favorites(limit)` 两个 LangChain 工具，让自然语言"把我最近拍的那张樱花存进收藏"真正可用。
3. **解锁新的情感留存闭环**。"删除"→"回收站"已是减法叙事；"收藏"是加法叙事，正好与情绪色彩日历（昨天的建议）形成"发现 → 标记 → 沉淀"链条：用户看到情绪日历某天颜色特别 → 跳转当日 → 看到喜欢的照片一键收藏。
4. **不上 AI 也能用，无需 GPU**。这与 AI 类的功能（Ollama、AI 描述生成等）形成对照——这是一个"任何部署环境都能开箱即用"的兜底能力，对低配 / 离线部署用户尤其友好。
5. **可观测的依赖图小到可以放心落地**。`PhotoLightbox.vue` / `FlatPhotoGallery.vue` / `Sidebar.vue` / `RecycleBinPage.vue` / `AlbumDetail.vue` / `HomePage.vue` 6 个文件的改动相互独立，新页面可以单独建 `views/favorites/index.vue`，风险面小、回滚容易。

## 功能细节

### 页面描述

**`/favorites` 一级页面（`views/favorites/index.vue`，预估 250-300 行）**

骨架 1:1 复用 `RecycleBinPage.vue`（299 行）的结构：

- 顶栏：左侧返回按钮（`router.back()`） + 标题"我的收藏" + 副标题"共 {{ total }} 张"；右侧一个 `el-segmented`（"全部 | 按相册 | 按位置 | 按人物 | 按时间"），切换时把 `viewMode` 写进 query 触发列表切换。
- 主体：`FlatPhotoGallery`，photos 来自 `photoStore.loadPhotos({ only_favorite: true, group_by: viewMode })`。`delete-label` 改为"取消收藏"，点击后调 `POST /api/medias/{id}/favorite` 切换，乐观更新本地 `photos` 列表立刻移除该卡片，失败回弹 `ElMessage.warning('已恢复')`。
- 空状态：复用 `PhotosPage.vue` L80 那种 `FolderPlus` 风格的大圆图标 + 文案"还没有收藏" + 一行引导"在照片上点 ♥ 标记你的心水之作"，底部加一个"去发现"按钮跳 `/photos`。
- 底部统计条（移动端折叠）：左侧三个小数字（"今日新增 N / 本周 N / 本月 N"），右侧一个"导出收藏"次级按钮（v1 可只 `console.log` 占位，后续接入 Issue #72「批量导出」）。

**HomePage 的"我的收藏"小卡**

**Lightbox 工具栏**

`PhotoLightbox.vue` 的 `Download` 之后插入：

```vue
<button
  @click.stop="toggleFavorite"
  class="w-8 h-8 md:w-12 md:h-12 flex items-center justify-center rounded-full hover:bg-white/10 transition-colors bg-transparent p-0"
  :class="image?.is_favorite ? 'text-rose-500' : 'text-white/90'"
  :title="image?.is_favorite ? '取消收藏' : '收藏'"
>
  <component :is="image?.is_favorite ? HeartFilled : Heart" class="w-6 h-6" />

```

收藏时叠加一个 200ms 的 `transform: scale(1.3)` → `scale(1)` 弹跳。

**`FlatPhotoGallery` 批量栏**

`add-to-album` 之后插入：

```vue
<button
  @click="$emit('batch-favorite', Array.from(localSelectedIds))"
  :disabled="localSelectedIds.size === 0"
  class="p-2 text-rose-500 hover:bg-rose-50 dark:hover:bg-rose-900/20 rounded-lg disabled:opacity-50"

```

`PhotosPage.vue` 的 `template #batch-actions` slot 与 `RecycleBinPage.vue` 同一插槽位置同步加一个 `el-dropdown-item`。

### 页面风格

- **主题色映射**：按 AGENTS.md 规范，所有 accent 都用 `text-rose-500` 这一**唯一定制色**——它不在 `useTheme.ts` 的 5 套主题里，但**红色作为收藏/情感的通用语**比跟主题色更直觉（sky/emerald/violet/amber 蓝色/绿色/紫色/橙色的主题一旦变成玫红会非常违和）。参考 GitHub Star、Twitter Like、Pixiv 收藏——都是独立于主题的红/粉系。可以考虑后续把 `rose` 加入 `useTheme.ts` 第六个可选主题，但本次保持现状。
- **空状态**：与 `PhotosPage.vue` L80 的 `FolderPlus` 大圆图标 + 主色边框保持同一模板，但圆背景从 `bg-primary-50` 改为 `bg-rose-50 dark:bg-rose-900/20`，icon 用 `Heart` 而不是 `FolderPlus`，形成"收藏版"的孪生兄弟——视觉一致但语义清晰区分。
- **画廊栅格**：`FlatPhotoGallery` 默认的 3-4 列 masonry 不变；卡片右下角悬浮一颗小 `Heart` 半透明角标（仅当 `is_favorite` 为 true），与 `RecycleBinPage.vue` 的"X 天后删除"角标位置完全一致，复用 `#overlay-actions` slot。
- **弹跳动效**：Lightbox 切换收藏时执行 `el-transition-group` 的"脉冲"——`@keyframes heart-pop { 0% { transform: scale(1); } 40% { transform: scale(1.3); } 100% { transform: scale(1); } }`，200ms `ease-out`，暗色模式不需要调整透明度。
- **暗色适配**：`Heart` 角标在暗背景用 `text-rose-400`（比 500 略降一档亮度，避免发光感太重），`bg-rose-900/20` 与现有其他深色容器保持同一色阶。
- **焦点环**：所有收藏相关 `RouterLink` / `button` 走 `focus-visible:ring-2 focus-visible:ring-rose-500 focus-visible:ring-offset-2 focus-visible:outline-none`（这里 rose 故意不跟主题色，因为它的语义是"心"——如果以后想跟主题，把 rose 也加进 `useTheme.ts` 即可）。
- **键盘可达**：Lightbox 工具栏新增的爱心按钮在 `tabindex=0` 的 `div` 内自然可达；批量栏的按钮在 `el-dropdown-item` 内也已天然支持 Enter/Space。
- **不要做的事**：不要做"双击图片收藏"的快捷手势（容易与 Lightbox 的双击放大冲突）；不要做"自动收藏所有 5 星 EXIF 照片"这种 AI 自动化（占用模型配额，但价值不及显式主动标记）。
