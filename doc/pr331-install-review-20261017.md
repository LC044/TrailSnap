# PR #331 Windows 安装与导入复核（2026-10-17）

本轮基线为 PR 提交 `354fcc31d3f4b5a8658d3fa735679e1de457b4d6`。修复在独立工作树 `TrailSnap-review-331-20261017` 完成，并按用户后续授权本地提交；未推送、合并或发布，未操作用户真实图库。本文只记录本轮结果，不沿用此前测试数量作为本轮证据。

## 发现及修复

1. 库内自定义整理目录及部分遗留内部路径在复制、发布临时目录后可能失效。保留内部存储根，登记遗留内部路径，在最终目录重绑并使用来源媒体基准验证；SQL 路径查询同步处理实例根目录。
2. 安装器原来会结束程序及后台任务。现在检测到对应安装目录仍有进程即拒绝覆盖/卸载，要求安全退出，不结束写入任务。
3. 导入前零照片图库仍可能包含账号、设置等数据。现在始终记录返回入口，明确两边不合并、不自动同步。
4. 实包覆盖安装发现旧资源目录残留可改变版本身份。安装前仅清理已检查的程序暂存目录，拒绝链接、含数据库或指向该目录的数据配置；保留实例、图库及快照。
5. 实包卸载后重装发现配置仍引用已删除程序版本。增加专用安装准备及恢复事务，验证候选前创建快照，失败还原配置和数据，成功提交；内部失败直接返回错误，避免静默安装被原生错误弹窗卡住。
6. Tauri 为 NSIS 修改可执行文件中的打包类型标记，导致 ZIP/NSIS 身份不同。仅在身份计算时统一已知标记，程序文件字节不修改，其他代码变化仍产生不同身份。
7. 冻结后端在中文 Windows 下输出 GBK，原生客户端按 UTF-8 读取导致发现旧库失败。显式配置 stdout/stderr UTF-8，使用强制 GBK 环境及真实冻结程序复验。
8. 历史 SQLite 照片的 upload_time 可以为空，导入后照片列表却因响应校验返回 500。响应模型接受该历史值，真实导入图库的列表及原图读取均已复验。
9. 首次安装时更新目录不存在或离线，不应提示“更新未完成”。自动检查失败保持安静，手动检查显示原因，实际下载失败及已有回滚提示仍保留。
10. 普通用户界面默认自动选择检测到的旧库，其他来源、备份范围和高级信息折叠；默认包含外部原照片，不复制时持续提示原盘依赖。历史全局卸载项仅在路径匹配且新卸载项已建立时清理，其他安装不受影响。
